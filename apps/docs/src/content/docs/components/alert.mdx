## 基础用法

`tone` 决定语义颜色（info / success / warning / error）。`title` 是可选的强调标题。
`closable` 让条目右侧带一个 × 按钮，点击后元素从 DOM 中移除。

<DemoFrame
  vueCode={`<Alert tone="info" title="一条信息">这是一段补充说明。</Alert>
<Alert tone="success" title="保存成功">数据已写入后端。</Alert>
<Alert tone="warning" title="磁盘空间不足">剩余空间小于 10%。</Alert>
<Alert tone="error" title="无法连接到服务" closable>
  请检查网络后重试。
</Alert>`}
  reactCode={`<Alert tone="info" title="一条信息">这是一段补充说明。</Alert>

<Alert tone="error" title="无法连接到服务" closable>
  请检查网络后重试。
</Alert>`}
>
  <BasicVue client:load />
</DemoFrame>

## 视觉变体

3 种 `variant` 改变背景与边框：`soft`（浅色背景，默认）、`outline`（透明背景 + 边框）、`solid`（满色背景）。

<DemoFrame
  vueCode={`<Alert tone="success" variant="soft">soft —— 浅色背景</Alert>
<Alert tone="success" variant="outline">outline —— 透明 + 同色边框</Alert>
<Alert tone="success" variant="solid">solid —— 满色背景</Alert>`}
  reactCode={`<Alert tone="success" variant="soft">soft —— 浅色背景</Alert>
<Alert tone="success" variant="outline">outline —— 透明 + 同色边框</Alert>

## API

| Prop       | 类型                                               | 默认值     | 说明                       |
| ---------- | -------------------------------------------------- | ---------- | -------------------------- |
| `tone`     | `'info' \| 'success' \| 'warning' \| 'error'`      | `'info'`   | 语义颜色                   |
| `variant`  | `'soft' \| 'outline' \| 'solid'`                   | `'soft'`   | 视觉变体                   |
| `title`    | `string`                                           | —          | 加粗的强调标题             |
| `icon`     | `boolean`                                          | `true`     | 是否显示左侧 status 图标   |
| `closable` | `boolean`                                          | `false`    | 是否显示右侧 × 按钮        |

### 事件

- Vue：`@close` —— 用户点击关闭按钮时触发
- React：`onClose` —— 同上
