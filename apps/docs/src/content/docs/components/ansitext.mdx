## 基础用法

支持基础 16 色（前景 + 背景）+ bright 8 色 + 修饰（bold / dim / italic / underline / inverse）。
颜色映射到 token，与主题一致；不解析 24-bit truecolor 转义。

<DemoFrame
  vueCode={`<CfAnsiText :text="terminalOutput" />`}
  reactCode={`<CfAnsiText text={terminalOutput} />`}
>
  <BasicVue client:load />
</DemoFrame>

## API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `text` | `string` | — | 含 ANSI 转义的字符串 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | |
| `wrap` | `boolean` | `true` | 软换行 |
| `preserveWhitespace` | `boolean` | `true` | `<pre>` 行为 |

支持的 SGR 代码：`0 1 2 3 4 7 22 23 24 27 30-37 39 40-47 49 90-97 100-107`。
