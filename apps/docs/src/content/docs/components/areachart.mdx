## 基础用法

数据通过 props 传入，纯 SVG 渲染，无第三方图表库依赖。
配色取自 `--viz-1..8` token，色盲友好。

<DemoFrame
  vueCode={`<CfAreaChart ... />`}
  reactCode={`<CfAreaChart ... />`}
>
  <BasicVue client:load />
</DemoFrame>

## API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `series` | `AreaSeries[]` | `—` | &#123; name?, data: number[] &#125;[] |
| `stacked` | `boolean` | `false` | 堆叠模式 |
| `smooth` | `boolean` | `false` | 平滑 |
| `width / height / showGrid / showLabels` | `` | `` | 同 LineChart |
