## 基础用法

数据通过 props 传入，纯 SVG 渲染，无第三方图表库依赖。
配色取自 `--viz-1..8` token，色盲友好。

<DemoFrame
  vueCode={`<CfAreaChart ... />`}
  reactCode={`<CfAreaChart ... />`}

  vueSource={BasicVueSource}>
  <BasicVue client:load />
</DemoFrame>


## 堆叠模式

`stacked = true` 把 series 累加显示（每条数据值是前面所有 series 的累加值），
适合展示组成；默认 false 重叠显示，适合比较趋势。

import StackedVue from '~/components/demos/areachart/StackedVue.vue';
import StackedVueSource from '~/components/demos/areachart/StackedVue.vue?raw';

<DemoFrame
  vueCode={`<CfAreaChart :series="series" stacked smooth />`}
  reactCode={`<CfAreaChart series={series} stacked smooth />`}

  vueSource={StackedVueSource}>
  <StackedVue client:load />
</DemoFrame>

## API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `series` | `AreaSeries[]` | `—` | &#123; name?, data: number[] &#125;[] |
| `stacked` | `boolean` | `false` | 堆叠模式 |
| `smooth` | `boolean` | `false` | 平滑 |
| `width / height / showGrid / showLabels` | `` | `` | 同 LineChart |
