## 基础用法

`ratio` 是一个数字（宽 / 高）。容器宽度跟随父元素，高度由 CSS `aspect-ratio` 计算。

<DemoFrame
  vueCode={`<CfAspectRatio :ratio="16 / 9">
  <div>16 / 9 内容</div>
</CfAspectRatio>`}
  reactCode={`<CfAspectRatio ratio={16 / 9}>
  <div>16 / 9 内容</div>
</CfAspectRatio>`}

  vueSource={BasicVueSource}>
  <BasicVue client:load />
</DemoFrame>

## 子元素自动撑满

子节点会被 `position: absolute; inset: 0` 撑满。常见的 `<img>` / `<video>` / `<iframe>` 默认 `width: 100%; height: 100%; object-fit: cover`，开箱即用。

<DemoFrame
  vueCode={`<CfAspectRatio :ratio="16 / 9">
  <img src="cover.jpg" alt="封面" />
</CfAspectRatio>

<CfAspectRatio :ratio="16 / 9">
  <iframe src="https://www.youtube.com/embed/..." allowfullscreen />
</CfAspectRatio>`}
  reactCode={`<CfAspectRatio ratio={16 / 9}>
  <img src="cover.jpg" alt="封面" />
</CfAspectRatio>

<CfAspectRatio ratio={16 / 9}>
  <iframe src="https://www.youtube.com/embed/..." allowFullScreen />
</CfAspectRatio>`}

  vueSource={ImageVueSource}>
  <ImageVue client:load />
</DemoFrame>

## API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `ratio` | `number` | `16 / 9` | 宽 / 高比。常用值：`21/9` `16/9` `4/3` `1` `3/4` `9/16` |
