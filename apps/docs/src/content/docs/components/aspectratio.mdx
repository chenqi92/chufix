## 基础用法

`ratio` 是一个数字（宽 / 高）。容器宽度跟随父元素，高度由 `aspect-ratio` 计算。子节点自动 `position: absolute; inset: 0`，常见的 `<img>` / `<video>` / `<iframe>` 默认 `width:100%; height:100%; object-fit: cover`。

<DemoFrame
  vueCode={`<CfAspectRatio :ratio="16 / 9">
  <div>16 / 9</div>
</CfAspectRatio>
<CfAspectRatio :ratio="4 / 3">
  <div>4 / 3</div>
</CfAspectRatio>
<CfAspectRatio :ratio="1">
  <div>1 / 1</div>
</CfAspectRatio>`}
  reactCode={`<CfAspectRatio ratio={16 / 9}><div>16 / 9</div></CfAspectRatio>
<CfAspectRatio ratio={4 / 3}><div>4 / 3</div></CfAspectRatio>
<CfAspectRatio ratio={1}><div>1 / 1</div></CfAspectRatio>`}
>
  <BasicVue client:load />
</DemoFrame>

## API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `ratio` | `number` | `16 / 9` | 宽 / 高比。常用值：`16/9` `4/3` `1` `9/16` `21/9` |
