4 个 API 的 p25/median/p75 + outliers，竖线显示完整 min-max 范围。

## API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `data` | `BoxStat[]` | `—` | `{ label, min, q1, median, q3, max, outliers? }[]` |
| `width` | `number` | `480` | SVG 宽度 |
| `height` | `number` | `240` | SVG 高度 |
| `ariaLabel` | `string` | `—` | 透传给根 `<svg>` 的 `aria-label` |
