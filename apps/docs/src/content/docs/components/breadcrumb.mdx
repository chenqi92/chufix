title: Breadcrumb 面包屑
description: 当前位置链路导航，最后一项为当前页（不可点）。

import DemoFrame from '~/components/DemoFrame.astro';
import BasicVue from '~/components/demos/breadcrumb/BasicVue.vue';

## 基础用法

`items` 数组每项 `{ label, href? }`。最后一项的 `href` 会被忽略（永远是当前页）。

<DemoFrame
  vueCode={`<script setup lang="ts">
import { CfBreadcrumb } from '@chufix/vue';

const items = [
  { label: '首页', href: '/' },
  { label: '组件', href: '/components/' },
  { label: 'Breadcrumb 面包屑' },
];
</script>

<template>
  <CfBreadcrumb :items="items" />
  <CfBreadcrumb :items="items" separator="›" />
</template>`}
  reactCode={`import { CfBreadcrumb } from '@chufix/react';

const items = [
  { label: '首页', href: '/' },
  { label: '组件', href: '/components/' },
  { label: 'Breadcrumb 面包屑' },
];

<CfBreadcrumb items={items} />
<CfBreadcrumb items={items} separator="›" />`}
>
  <BasicVue client:load />
</DemoFrame>

## API

| Prop        | 类型                                  | 默认值 | 说明                          |
| ----------- | ------------------------------------- | ------ | ----------------------------- |
| `items`     | `Array<{ label: string; href?: string }>` | `[]`   | 链路项；最后一项作为当前页    |
| `separator` | `string`                              | `'/'`  | 分隔符；常用 `›` `·` 或自定义 |
