## 基础用法

数据通过 props 传入，纯 SVG 渲染，无第三方图表库依赖。
配色取自 `--viz-1..8` token，色盲友好。

<DemoFrame
  vueCode={`<CfBulletChart ... />`}
  reactCode={`<CfBulletChart ... />`}
>
  <BasicVue client:load />
</DemoFrame>

## API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `value` | `number` | `—` | 当前值 |
| `target` | `number` | `—` | 目标值（垂直线） |
| `max` | `number` | `—` | 最大值 |
| `bands` | `{ upTo: number; tone? }[]` | `[]` | 质量带（poor/ok/good） |
| `label` | `string` | `—` |  |
