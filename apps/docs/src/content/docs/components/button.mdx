## 基础用法

5 种视觉变体覆盖从主操作到次操作的全部层级。`solid` 是默认的实心按钮，`link` 退化成纯文字链接。

<DemoFrame
  vueCode={`<script setup lang="ts">
import { Button } from '@chufix/vue';
</script>

<template>
  <Button>Solid</Button>
  <Button variant="soft">Soft</Button>
  <Button variant="outline">Outline</Button>
  <Button variant="ghost">Ghost</Button>
  <Button variant="link">Link</Button>
</template>`}
  reactCode={`import { Button } from '@chufix/react';

export default function Demo() {
  return (
    <>
      <Button>Solid</Button>
      <Button variant="soft">Soft</Button>
      <Button variant="outline">Outline</Button>
      <Button variant="ghost">Ghost</Button>
      <Button variant="link">Link</Button>
    </>
  );
}`}
>
  <BasicVue client:load />
</DemoFrame>

## 状态

`loading` 自动渲染 spinner 并阻止点击；`disabled` 让按钮不可交互；`block` 让宽度铺满父容器。

<DemoFrame
  vueCode={`<script setup lang="ts">
import { ref } from 'vue';
import { Button } from '@chufix/vue';

const loading = ref(false);
async function load() {
  loading.value = true;
  await new Promise((r) => setTimeout(r, 1500));
  loading.value = false;
}
</script>

<template>
  <Button :loading="loading" @click="load">
    {{ loading ? '加载中…' : '点击加载' }}
  </Button>
  <Button disabled>Disabled</Button>
  <Button block>整行铺满（block）</Button>
</template>`}
  reactCode={`import { useState } from 'react';
import { Button } from '@chufix/react';

export default function Demo() {
  const [loading, setLoading] = useState(false);
  async function load() {
    setLoading(true);
    await new Promise((r) => setTimeout(r, 1500));
    setLoading(false);
  }

  return (
    <>
      <Button loading={loading} onClick={load}>
        {loading ? '加载中…' : '点击加载'}
      </Button>
      <Button disabled>Disabled</Button>
      <Button block>整行铺满（block）</Button>
    </>
  );
}`}
>
  <StatesVue client:load />
</DemoFrame>

## API

| Prop       | 类型                                                       | 默认值       | 说明                                |
| ---------- | ---------------------------------------------------------- | ------------ | ----------------------------------- |
| `variant`  | `'solid' \| 'soft' \| 'outline' \| 'ghost' \| 'link'`      | `'solid'`    | 视觉变体                            |
| `size`     | `'sm' \| 'md' \| 'lg'`                                     | `'md'`       | 高度与字号                          |
| `shape`    | `'default' \| 'pill' \| 'square'`                          | `'default'`  | 圆角形状                            |
| `tone`     | `'primary' \| 'danger'`                                    | `'primary'`  | 语义色                              |
| `loading`  | `boolean`                                                  | `false`      | 显示 spinner 并阻止点击             |
| `block`    | `boolean`                                                  | `false`      | 撑满父容器宽度                      |
| `disabled` | `boolean`                                                  | `false`      | 禁用                                |

### 插槽 / Children

- **Vue**：默认插槽是 label，`leading` / `trailing` 具名插槽放图标。
- **React**：`children` 是 label，`leading` / `trailing` props 放图标节点。
