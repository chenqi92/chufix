## 基础用法

切换到「Vue」或「React」标签可以查看对应源码并一键复制；预览区里的两个实例都是真实可交互的组件，不是截图。

<DemoFrame
  vueCode={`<script setup lang="ts">
import { ref } from 'vue';
import { Button } from '@chukit/vue';

const count = ref(0);
const loading = ref(false);

async function load() {
  loading.value = true;
  await new Promise((r) => setTimeout(r, 1200));
  loading.value = false;
}
</script>

<template>
  <Button @click="count++">点击 {{ count }}</Button>
  <Button variant="soft">Soft</Button>
  <Button variant="outline">Outline</Button>
  <Button variant="ghost">Ghost</Button>
  <Button tone="danger">Danger</Button>
  <Button :loading="loading" @click="load">
    {{ loading ? '加载中' : '点击加载' }}
  </Button>
</template>`}
  reactCode={`import { useState } from 'react';
import { Button } from '@chukit/react';

export default function Demo() {
  const [count, setCount] = useState(0);
  const [loading, setLoading] = useState(false);

  async function load() {
    setLoading(true);
    await new Promise((r) => setTimeout(r, 1200));
    setLoading(false);
  }

  return (
    <>
      <Button onClick={() => setCount((c) => c + 1)}>点击 {count}</Button>
      <Button variant="soft">Soft</Button>
      <Button variant="outline">Outline</Button>
      <Button variant="ghost">Ghost</Button>
      <Button tone="danger">Danger</Button>
      <Button loading={loading} onClick={load}>
        {loading ? '加载中' : '点击加载'}
      </Button>
    </>
  );
}`}
>
  <BasicVue slot="vue" client:load />
  <BasicReact slot="react" client:load />
</DemoFrame>

## Props

| 名称       | 类型                                                       | 默认值     | 说明                                |
| ---------- | ---------------------------------------------------------- | ---------- | ----------------------------------- |
| `variant`  | `'solid' \| 'soft' \| 'outline' \| 'ghost' \| 'link'`     | `'solid'`  | 视觉变体                            |
| `size`     | `'sm' \| 'md' \| 'lg'`                                     | `'md'`     | 高度与字号                          |
| `shape`    | `'default' \| 'pill' \| 'square'`                          | `'default'`| 圆角形状；`square` 适合 icon-only   |
| `tone`     | `'primary' \| 'danger'`                                    | `'primary'`| 语义色                              |
| `loading`  | `boolean`                                                  | `false`    | 显示 spinner 并阻止点击             |
| `block`    | `boolean`                                                  | `false`    | 撑满父容器宽度                      |
| `disabled` | `boolean`                                                  | `false`    | 禁用                                |

## 插槽 / Children

- **Vue**：默认插槽为 label，`leading` / `trailing` 具名插槽放图标。
- **React**：`children` 为 label，`leading` / `trailing` props 放图标节点。
