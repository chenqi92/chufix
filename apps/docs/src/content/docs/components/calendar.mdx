## 基础用法

`CfCalendar` 是嵌入式月视图。选中日期通过 `v-model` (Vue) / `value` + `onChange` (React) 暴露。

<DemoFrame
  vueCode={`<CfCalendar v-model="date" show-week-numbers />`}
  reactCode={`<CfCalendar value={date} onChange={setDate} showWeekNumbers />`}
>
  <BasicVue client:load />
</DemoFrame>

## API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `modelValue` (Vue) / `value` (React) | `Date \| null` | `null` | 当前选中日期 |
| `month` | `Date` | `今天所在月` | 受控显示月份 |
| `min` / `max` | `Date` | `—` | 可选范围，外侧禁用 |
| `weekStartsOn` | `0 \| 1` | `1` | 0=周日 1=周一 |
| `showWeekNumbers` | `boolean` | `false` | 显示周序号列 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 整体字号 |
| `disabled` | `boolean` | `false` | 禁用全部交互 |
