## 基础用法

数据通过 props 传入，纯 SVG 渲染，无第三方图表库依赖。
配色取自 `--viz-1..8` token，色盲友好。

<DemoFrame
  vueCode={`<CfCandlestickChart ... />`}
  reactCode={`<CfCandlestickChart ... />`}
>
  <BasicVue client:load />
</DemoFrame>


## 上行 / 下行趋势

红绿涨跌染色由 `close >= open` 自动判定，wick 与 body 同色。

import UpDownVue from '~/components/demos/candlestickchart/UpDownVue.vue';

<DemoFrame
  vueCode={`<CfCandlestickChart :data="ohlc" />`}
  reactCode={`<CfCandlestickChart data={ohlc} />`}
>
  <UpDownVue client:load />
</DemoFrame>
