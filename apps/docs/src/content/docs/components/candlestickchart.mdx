## API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `data` | `Candle[]` | `—` | `{ open, high, low, close, label? }[]` |
| `width` | `number` | `480` | SVG 宽度 |
| `height` | `number` | `240` | SVG 高度 |
| `ariaLabel` | `string` | `—` | 透传给根 `<svg>` 的 `aria-label` |

### Events

| Vue 事件 | React 回调 | 载荷类型 | 说明 |
|---|---|---|---|
| `item-enter` | `onItemEnter` | `CandlestickChartInteractionPayload` | 鼠标进入某根蜡烛时触发 |
| `item-leave` | `onItemLeave` | `CandlestickChartInteractionPayload` | 鼠标离开某根蜡烛时触发 |

### 类型

```ts
interface CandlestickChartInteractionPayload {
  candle: Candle;
  dataIndex: number;
  nativeEvent?: PointerEvent;
}
```
