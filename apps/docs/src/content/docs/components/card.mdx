## 基础用法

Vue 用具名插槽 `header` / `footer` + 默认插槽作为 body；React 用 `CardHeader` / `CardBody` / `CardFooter` 子组件组合 —— 两种风格映射到同一套 CSS。

<DemoFrame
  vueCode={`<script setup lang="ts">
import { Card, Button } from '@chukit/vue';
</script>

<template>
  <Card variant="outlined">
    <template #header>Outlined</template>
    默认边框 + 微弱阴影。
    <template #footer>
      <Button size="sm" variant="ghost">取消</Button>
      <Button size="sm">确认</Button>
    </template>
  </Card>

  <Card variant="elevated">
    <template #header>Elevated</template>
    去掉边框、提升阴影。
  </Card>

  <Card variant="filled" interactive @click="onClick">
    <template #header>Filled · 可点击</template>
    整张卡片作为入口。
  </Card>
</template>`}
  reactCode={`import { Card, CardHeader, CardBody, CardFooter, Button } from '@chukit/react';

export default function Demo() {
  return (
    <>
      <Card variant="outlined">
        <CardHeader>Outlined</CardHeader>
        <CardBody>默认边框 + 微弱阴影。</CardBody>
        <CardFooter>
          <Button size="sm" variant="ghost">取消</Button>
          <Button size="sm">确认</Button>
        </CardFooter>
      </Card>

      <Card variant="elevated">
        <CardHeader>Elevated</CardHeader>
        <CardBody>去掉边框、提升阴影。</CardBody>
      </Card>

      <Card variant="filled" interactive onClick={onClick}>
        <CardHeader>Filled · 可点击</CardHeader>
        <CardBody>整张卡片作为入口。</CardBody>
      </Card>
    </>
  );
}`}
>
  <BasicVue slot="vue" client:load />
  <BasicReact slot="react" client:load />
</DemoFrame>

## Props

| 名称          | 类型                                       | 默认值        | 说明                            |
| ------------- | ------------------------------------------ | ------------- | ------------------------------- |
| `variant`     | `'elevated' \| 'outlined' \| 'filled'`     | `'outlined'`  | 视觉变体                        |
| `interactive` | `boolean`                                  | `false`       | 整卡可点击 + hover 上浮 + 焦点态 |
| `as` *(Vue)*  | `string`                                   | `'div'`       | 渲染为指定标签                  |

## 组合方式

- **Vue**：`<template #header>` / 默认插槽 / `<template #footer>`，三段都可省略。
- **React**：`<CardHeader>` / `<CardBody>` / `<CardFooter>` 任意组合，未使用的段落不渲染。
