## 基础用法

最简的 Card 只渲染默认插槽（Vue）/ children（React），用于包裹一段内容并加边框。

<DemoFrame
  vueCode={`<script setup lang="ts">
import { Card } from '@chufix/vue';
</script>

<template>
  <Card>
    <p>最简卡片，只渲染默认插槽。</p>
  </Card>
</template>`}
  reactCode={`import { Card } from '@chufix/react';

export default function Demo() {
  return (
    <Card>
      <p>最简卡片，只渲染 children。</p>
    </Card>
  );
}`}
>
  <BasicVue client:load />
</DemoFrame>

## 视觉变体

3 种 variant 在不同信息层级使用：`outlined`（默认描边）/ `elevated`（带阴影）/ `filled`（浅灰填充）。

<DemoFrame
  vueCode={`<Card variant="outlined">…</Card>
<Card variant="elevated">…</Card>
<Card variant="filled">…</Card>`}
  reactCode={`<Card variant="outlined">…</Card>
<Card variant="elevated">…</Card>
<Card variant="filled">…</Card>`}
>
  <VariantsVue client:load />
</DemoFrame>

## 三段式结构

Vue 用具名插槽 `header` / `footer`，React 用子组件 `CardHeader` / `CardBody` / `CardFooter`。任意一段都可省略。

<DemoFrame
  vueCode={`<Card variant="elevated">
  <template #header>项目设置</template>
  <p>这是一段卡片正文。</p>
  <template #footer>
    <Button size="sm" variant="outline">取消</Button>
    <Button size="sm">保存</Button>
  </template>
</Card>`}
  reactCode={`import { Button, Card, CardHeader, CardBody, CardFooter } from '@chufix/react';

export default function Demo() {
  return (
    <Card variant="elevated">
      <CardHeader>项目设置</CardHeader>
      <CardBody>
        <p>这是一段卡片正文。</p>
      </CardBody>
      <CardFooter>
        <Button size="sm" variant="outline">取消</Button>
        <Button size="sm">保存</Button>
      </CardFooter>
    </Card>
  );
}`}
>
  <SectionsVue client:load />
</DemoFrame>

## 整卡可点击

打开 `interactive` 后，整张卡片变成按钮 —— 自动加 `role="button"` + `tabindex="0"`，键盘 Enter 可触发 `click`。

<DemoFrame
  vueCode={`<Card variant="outlined" interactive @click="clicked++">
  <template #header>整卡可点击</template>
  <p>已点击 {{ clicked }} 次</p>
</Card>`}
  reactCode={`<Card variant="outlined" interactive onClick={() => setClicked(c => c + 1)}>
  <CardHeader>整卡可点击</CardHeader>
  <CardBody>已点击 {clicked} 次</CardBody>
</Card>`}
>
  <InteractiveVue client:load />
</DemoFrame>

## API

| Prop          | 类型                                         | 默认值       | 说明                            |
| ------------- | -------------------------------------------- | ------------ | ------------------------------- |
| `variant`     | `'outlined' \| 'elevated' \| 'filled'`       | `'outlined'` | 视觉变体                        |
| `interactive` | `boolean`                                    | `false`      | 整卡变成按钮（focus / hover）   |
| `as`          | `string`（Vue）                              | `'div'`      | 渲染的 HTML tag                 |
