## 基础用法

最简的 Card 只渲染默认插槽（Vue）/ children（React），用于包裹一段内容并加边框。

<DemoFrame
  vueCode={`<script setup lang="ts">
import { CfCard } from '@chufix-design/vue';
</script>

<template>
  <CfCard>
    <p>最简卡片，只渲染默认插槽。</p>
  </CfCard>
</template>`}
  reactCode={`import { CfCard } from '@chufix-design/react';

export default function Demo() {
  return (
    <CfCard>
      <p>最简卡片，只渲染 children。</p>
    </CfCard>
  );
}`}
>
  <BasicVue client:load />
</DemoFrame>

## 视觉变体

3 种 variant 在不同信息层级使用：`outlined`（默认描边）/ `elevated`（带阴影）/ `filled`（浅灰填充）。

<DemoFrame
  vueCode={`<CfCard variant="outlined">…</CfCard>
<CfCard variant="elevated">…</CfCard>
<CfCard variant="filled">…</CfCard>`}
  reactCode={`<CfCard variant="outlined">…</CfCard>
<CfCard variant="elevated">…</CfCard>
<CfCard variant="filled">…</CfCard>`}
>
  <VariantsVue client:load />
</DemoFrame>

## 三段式结构

Vue 用具名插槽 `header` / `footer`，React 用子组件 `CardHeader` / `CardBody` / `CardFooter`。任意一段都可省略。

<DemoFrame
  vueCode={`<CfCard variant="elevated">
  <template #header>项目设置</template>
  <p>这是一段卡片正文。</p>
  <template #footer>
    <CfButton size="sm" variant="tertiary">取消</CfButton>
    <CfButton size="sm">保存</CfButton>
  </template>
</CfCard>`}
  reactCode={`import { CfButton, CfCard, CfCardHeader, CfCardBody, CfCardFooter } from '@chufix-design/react';

export default function Demo() {
  return (
    <CfCard variant="elevated">
      <CfCardHeader>项目设置</CfCardHeader>
      <CfCardBody>
        <p>这是一段卡片正文。</p>
      </CfCardBody>
      <CfCardFooter>
        <CfButton size="sm" variant="tertiary">取消</CfButton>
        <CfButton size="sm">保存</CfButton>
      </CfCardFooter>
    </CfCard>
  );
}`}
>
  <SectionsVue client:load />
</DemoFrame>

## 整卡可点击

打开 `interactive` 后，整张卡片变成按钮 —— 自动加 `role="button"` + `tabindex="0"`，键盘 Enter 可触发 `click`。

<DemoFrame
  vueCode={`<CfCard variant="outlined" interactive @click="clicked++">
  <template #header>整卡可点击</template>
  <p>已点击 {{ clicked }} 次</p>
</CfCard>`}
  reactCode={`<CfCard variant="outlined" interactive onClick={() => setClicked(c => c + 1)}>
  <CfCardHeader>整卡可点击</CfCardHeader>
  <CfCardBody>已点击 {clicked} 次</CfCardBody>
</CfCard>`}
>
  <InteractiveVue client:load />
</DemoFrame>

## API

| Prop          | 类型                                         | 默认值       | 说明                            |
| ------------- | -------------------------------------------- | ------------ | ------------------------------- |
| `variant`     | `'outlined' \| 'elevated' \| 'filled'`       | `'outlined'` | 视觉变体                        |
| `interactive` | `boolean`                                    | `false`      | 整卡变成按钮（focus / hover）   |
| `as`          | `string`（Vue）                              | `'div'`      | 渲染的 HTML tag                 |
