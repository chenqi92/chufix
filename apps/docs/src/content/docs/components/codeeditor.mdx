## 基础用法

定位是"视觉容器 + 轻交互"：行号、Tab 缩进、行尾保持、ARIA 标签齐全；不内置语法高亮。
若需高亮，让消费方在外层裹一个 overlay（参考 VariableAwareInput 的 overlay 技法）。

## API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `modelValue` / `value` | `string` | `''` | 代码内容 |
| `language` | `string` | `'plaintext'` | 仅作 `data-language` 透传，不参与渲染 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | |
| `showLineNumbers` | `boolean` | `true` | |
| `readOnly` | `boolean` | `false` | |
| `rows` | `number` | `12` | 可见行数 |
| `wrap` | `boolean` | `false` | 长行软换 |
| `tabSize` | `number` | `2` | Tab 插入空格数；0 表示让 Tab 移动焦点 |
