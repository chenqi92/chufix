## 基础用法

数据通过 props 传入，纯 SVG 渲染，无第三方图表库依赖。
配色取自 `--viz-1..8` token，色盲友好。

<DemoFrame
  vueCode={`<CfConnectionGraph ... />`}
  reactCode={`<CfConnectionGraph ... />`}
>
  <BasicVue client:load />
</DemoFrame>


## 微服务拓扑

7 个服务、7 条连线，展示典型 gateway 分发模式。

import MicroservicesVue from '~/components/demos/connectiongraph/MicroservicesVue.vue';

<DemoFrame
  vueCode={`<CfConnectionGraph :nodes="nodes" :edges="edges" />`}
  reactCode={`<CfConnectionGraph nodes={nodes} edges={edges} />`}
>
  <MicroservicesVue client:load />
</DemoFrame>

## API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `nodes` | `GraphNode[]` | `—` | &#123; id, label, x?, y?, colorIndex?, size? &#125;[] |
| `edges` | `GraphEdge[]` | `—` | &#123; source, target, weight?, colorIndex? &#125;[] |
| `showLabels` | `boolean` | `true` |  |
