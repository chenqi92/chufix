import DemoFrame from '~/components/DemoFrame.astro';
import BasicVue from '~/components/demos/contextmenu/BasicVue.vue';

## 基础用法

包裹目标区域，右键触发 `contextmenu` 事件后在光标位置显示菜单。`Esc` / 点击外部关闭。

<DemoFrame
  vueCode={`<CfContextMenu :items="items" @select="onPick">
  <div>右键这里</div>
</CfContextMenu>`}
  reactCode={`<CfContextMenu items={items} onSelect={onPick}>
  <div>右键这里</div>
</CfContextMenu>`}
>
  <BasicVue client:only="vue" />
</DemoFrame>


## 禁用 / 危险 / 分隔符

`disabled` 灰化、`danger` 红字、`separator: true` 画分隔行。

import NestedVue from '~/components/demos/contextmenu/NestedVue.vue';

<DemoFrame
  vueCode={`<CfContextMenu :items="items">…</CfContextMenu>`}
  reactCode={`<CfContextMenu items={items}>…</CfContextMenu>`}
>
  <NestedVue client:load />
</DemoFrame>

## API

`items: ContextMenuItem[]`，每项支持：

| 字段 | 类型 | 说明 |
|---|---|---|
| `label` | `string` | 文本 |
| `value` | `string` | 选中时的 value（默认回落 label） |
| `shortcut` | `string` | 右侧快捷键提示 |
| `disabled` | `boolean` | |
| `danger` | `boolean` | 红色样式 |
| `separator` | `boolean` | 分隔行（其他字段忽略） |
