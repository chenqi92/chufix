## 基础用法

`orientation` 控制方向，`variant` 控制线型，默认插槽是中部标签。

<DemoFrame
  vueCode={`<CfDivider />
<CfDivider variant="dashed">分组 A</CfDivider>
<CfDivider variant="dotted" align="start">日志</CfDivider>

<span>文本 <CfDivider orientation="vertical" /> 中间</span>`}
  reactCode={`<CfDivider />
<CfDivider variant="dashed">分组 A</CfDivider>
<CfDivider variant="dotted" align="start">日志</CfDivider>

<span>文本 <CfDivider orientation="vertical" /> 中间</span>`}
>
  <BasicVue client:load />
</DemoFrame>

## API

| Prop          | 类型                              | 默认值          | 说明                       |
| ------------- | --------------------------------- | --------------- | -------------------------- |
| `orientation` | `'horizontal' \| 'vertical'`      | `'horizontal'`  | 方向                       |
| `variant`     | `'solid' \| 'dashed' \| 'dotted'` | `'solid'`       | 线型                       |
| `align`       | `'start' \| 'center' \| 'end'`    | `'center'`      | 标签位置（仅 horizontal）  |
