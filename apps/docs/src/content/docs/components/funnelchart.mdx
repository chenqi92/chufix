## API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `steps` | `FunnelStep[]` | `—` | `{ label, value }[]`，从上到下值递减 |
| `width` | `number` | `360` | SVG 宽度 |
| `height` | `number` | `240` | SVG 高度 |
| `showLabels` | `boolean` | `true` | 显示每段的 label / value |
| `ariaLabel` | `string` | `—` | 透传给根 `<svg>` 的 `aria-label` |
