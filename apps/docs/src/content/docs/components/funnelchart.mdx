## 好坏漏斗对比

健康漏斗（每段流失 30-50%）vs 流失严重漏斗（92% 直接流失）。

import CompareVue from '~/components/demos/funnelchart/CompareVue.vue';

<DemoFrame
  vueCode={`<CfFunnelChart :steps="good" />
<CfFunnelChart :steps="bad" />`}
  reactCode={`<CfFunnelChart steps={good} />
<CfFunnelChart steps={bad} />`}
>
  <CompareVue client:load />
</DemoFrame>
