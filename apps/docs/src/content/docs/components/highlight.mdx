## 基础用法

`text` 是被高亮的原文，`match` 可以是字符串或正则；字符串模式默认大小写不敏感。

<DemoFrame
  vueCode={`<CfHighlight :text="text" :match="q" />`}
  reactCode={`<CfHighlight text={text} match={q} />`}

  vueSource={BasicVueSource}>
  <BasicVue client:load />
</DemoFrame>

## API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `text` | `string` | `—` | 原始文本 |
| `match` | `string \| RegExp` | `—` | 关键字或正则；为空时不高亮 |
| `caseSensitive` | `boolean` | `false` | 字符串模式下是否区分大小写 |
