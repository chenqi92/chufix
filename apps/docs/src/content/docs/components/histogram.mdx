## 基础用法

数据通过 props 传入，纯 SVG 渲染，无第三方图表库依赖。
配色取自 `--viz-1..8` token，色盲友好。

  vueCode={`<CfHistogram ... />`}
  reactCode={`<CfHistogram ... />`}
>
  <BasicVue client:load />
</DemoFrame>

## API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `bins` | `HistogramBin[]` | `—` | &#123; label, count &#125;[] |
| `colorIndex` | `0..7` | `0` |  |
| `showLabels` | `boolean` | `true` | bin label 显示开关 |
