## 基础用法

配色取自 `--viz-1..8` token，色盲友好。

## 两种典型分布

正态分布 / 长尾分布对比 — 长尾时建议用对数刻度的 bin label。

import DistributionsVue from '~/components/demos/histogram/DistributionsVue.vue';
import DistributionsVueSource from '~/components/demos/histogram/DistributionsVue.vue?raw';

<DemoFrame
  vueCode={`<CfHistogram :bins="bins" />`}
  reactCode={`<CfHistogram bins={bins} />`}

  vueSource={DistributionsVueSource}>
  <DistributionsVue client:load />
</DemoFrame>

## API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `bins` | `HistogramBin[]` | `—` | &#123; label, count &#125;[] |
| `colorIndex` | `0..7` | `0` |  |
| `showLabels` | `boolean` | `true` | bin label 显示开关 |
