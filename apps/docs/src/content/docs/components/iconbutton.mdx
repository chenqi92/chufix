## 基础用法

3 个 variant（`default` / `primary` / `danger`），3 档尺寸（`sm` / `md` / `lg`），形状 `square` / `round`。

`pressed` 用于 toggle 行为（pin / bookmark），自动设 `aria-pressed`。

<DemoFrame
  vueCode={`<CfIconButton aria-label="保存" variant="primary">

</CfIconButton>
<CfIconButton aria-label="删除" variant="danger">…</CfIconButton>
<CfIconButton aria-label="固定" :pressed="true">…</CfIconButton>`}

<CfIconButton aria-label="删除" variant="danger"><Icon /></CfIconButton>

## Toolbar 组合

`pressed` 与 `@click` 配合可以组装出格式化工具栏：粗体 / 斜体 / 下划线分别独立 toggle，
对齐方式互斥但展示用同一组按钮。同一行内用 1–2px 间距，必要时插入 `<span>` 分隔线分组。

<DemoFrame
  vueCode={`<script setup lang="ts">
import { ref } from 'vue';
import { CfIconButton, CfIcon } from '@chufix-design/vue';

const bold = ref(false);
const italic = ref(false);
</script>

<template>
  <div style="display: inline-flex; gap: 2px;">
    <CfIconButton :pressed="bold" aria-label="粗体" @click="bold = !bold">
      <CfIcon name="bold" />
    </CfIconButton>
    <CfIconButton :pressed="italic" aria-label="斜体" @click="italic = !italic">
      <CfIcon name="italic" />
    </CfIconButton>
  </div>
</template>`}
  reactCode={`import { useState } from 'react';
import { CfIconButton, CfIcon } from '@chufix-design/react';

export default function Demo() {
  const [bold, setBold] = useState(false);
  const [italic, setItalic] = useState(false);
  return (
    <div style={{ display: 'inline-flex', gap: 2 }}>
      <CfIconButton pressed={bold} aria-label="粗体" onClick={() => setBold(!bold)}>
        <CfIcon name="bold" />
      </CfIconButton>
      <CfIconButton pressed={italic} aria-label="斜体" onClick={() => setItalic(!italic)}>
        <CfIcon name="italic" />
      </CfIconButton>
    </div>
  );
}`}

  vueSource={ToolbarVueSource}>
  <ToolbarVue client:load />
</DemoFrame>

## 徽章

`badge` 具名插槽渲染右上角徽章，用于通知数量、未读标记等场景。短文案（"3"、"99+"）效果最好，
单点（"•"）适合纯"有新内容"提示。徽章自动定位、无需手写样式。

<DemoFrame
  vueCode={`<CfIconButton aria-label="通知（3 条未读）">
  <CfIcon name="bell" />
  <template #badge>3</template>
</CfIconButton>
<CfIconButton aria-label="邮件（99+ 封未读）">
  <CfIcon name="mail" />
  <template #badge>99+</template>
</CfIconButton>
<CfIconButton aria-label="收件箱（有新内容）">

</CfIconButton>

## API

### Props

| Prop       | 类型                                  | 默认值       | 说明                                  |
| ---------- | ------------------------------------- | ------------ | ------------------------------------- |
| `variant`  | `'default' \| 'primary' \| 'danger'`  | `'default'`  | 视觉变体                              |
| `size`     | `'sm' \| 'md' \| 'lg'`                | `'md'`       | 尺寸                                  |
| `shape`    | `'square' \| 'round'`                 | `'square'`   | 形状                                  |
| `pressed`  | `boolean`                             | `false`      | toggle 状态，输出 `aria-pressed`      |
| `loading`  | `boolean`                             | `false`      | 显示 spinner，自动屏蔽点击            |
| `disabled` | `boolean`                             | `false`      | 禁用                                  |
| `type`     | `'button' \| 'submit' \| 'reset'`     | `'button'`   | 原生 button type，用于 Form 提交场景  |

### Events

| Event   | 载荷类型     | 说明                                       |
| ------- | ------------ | ------------------------------------------ |
| `click` | `MouseEvent` | 点击触发；`disabled` 或 `loading` 时不触发 |

### Slots / Children

| Slot      | Props | 说明                                            |
| --------- | ----- | ----------------------------------------------- |
| `default` | —     | 图标内容；React 端等价为 `children`             |
| `badge`   | —     | 右上角徽章；React 端等价为 `badge` prop         |

> **a11y**：必须传 `aria-label`，否则屏幕阅读器无法识别按钮含义。
