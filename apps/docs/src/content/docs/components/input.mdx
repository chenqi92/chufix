## 基础用法

Vue 使用 `v-model`；React 用受控/非受控均可。第二个输入框开启了 `clearable`，输入文字后右侧会出现清空按钮。

<DemoFrame
  vueCode={`<script setup lang="ts">
import { ref } from 'vue';
import { Input } from '@chukit/vue';

const name = ref('');
const email = ref('user@chukit.dev');
</script>

<template>
  <Input v-model="name" placeholder="请输入名字" />
  <Input v-model="email" clearable placeholder="邮箱" />
  <Input v-model="pwd" type="password" placeholder="密码" />
</template>`}
  reactCode={`import { useState } from 'react';
import { Input } from '@chukit/react';

export default function Demo() {
  const [name, setName] = useState('');
  const [email, setEmail] = useState('user@chukit.dev');
  const [pwd, setPwd] = useState('');

  return (
    <>
      <Input value={name} onChange={(e) => setName(e.target.value)} placeholder="请输入名字" />
      <Input value={email} clearable onChange={(e) => setEmail(e.target.value)}
             onClear={() => setEmail('')} placeholder="邮箱" />
      <Input value={pwd} type="password" onChange={(e) => setPwd(e.target.value)} placeholder="密码" />
    </>
  );
}`}
>
  <BasicVue slot="vue" client:load />
  <BasicReact slot="react" client:load />
</DemoFrame>

## Props

| 名称           | 类型                                                       | 默认值      | 说明                                |
| -------------- | ---------------------------------------------------------- | ----------- | ----------------------------------- |
| `variant`      | `'outline' \| 'filled' \| 'ghost'`                         | `'outline'` | 视觉变体                            |
| `size` *(Vue)* / `inputSize` *(React)* | `'sm' \| 'md' \| 'lg'`                     | `'md'`      | 高度与字号                          |
| `type`         | `'text' \| 'password' \| 'email' \| 'number' \| ...`       | `'text'`    | 原生 input type                     |
| `error`        | `boolean`                                                  | `false`     | 错误态（红色边框 + ring）           |
| `clearable`    | `boolean`                                                  | `false`     | 有内容时显示清空按钮                |
| `disabled`     | `boolean`                                                  | `false`     | 禁用                                |
| `placeholder`  | `string`                                                   | —           | 占位文字                            |

> React 用 `inputSize` 而不是 `size`，是因为原生 `<input size>` 是字符长度属性，避免冲突。

## 插槽 / Children

- **Vue**：`prefix` / `suffix` 具名插槽；
- **React**：`prefix` / `suffix` props，传 `ReactNode`。
