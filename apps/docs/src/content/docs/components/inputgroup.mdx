## 基础用法

InputGroup 是一个纯样式包裹层。把表单控件按顺序放入它，子元素会自动去掉相邻的内圆角，并合并边框，第一个/最后一个元素继承外圆角。静态标签用 `<span class="cf-input-group__addon">` 渲染。

<DemoFrame
  vueCode={`<script setup lang="ts">
import { ref } from 'vue';
import { CfInputGroup, CfInput, CfButton, CfSelect } from '@chufix/vue';

const search = ref('');
const protocol = ref('https');
const host = ref('chufix.com');
const protocols = [
  { label: 'https://', value: 'https' },
  { label: 'http://', value: 'http' },
];
</script>

<template>
  <CfInputGroup>
    <span class="cf-input-group__addon">@</span>
    <CfInput v-model="search" placeholder="username" />
  </CfInputGroup>

  <CfInputGroup>
    <CfSelect v-model="protocol" :options="protocols" />
    <CfInput v-model="host" placeholder="example.com" />
    <CfButton>访问</CfButton>
  </CfInputGroup>

  <CfInputGroup stretch>
    <CfInput placeholder="搜索…" />
    <CfButton variant="primary">搜索</CfButton>
  </CfInputGroup>
</template>`}
  reactCode={`import { useState } from 'react';
import { CfInputGroup, CfInput, CfButton, CfSelect } from '@chufix/react';

export default function Demo() {
  const [search, setSearch] = useState('');
  const [host, setHost] = useState('chufix.com');
  const [protocol, setProtocol] = useState('https');
  return (
    <>
      <CfInputGroup>
        <span className="cf-input-group__addon">@</span>
        <CfInput value={search} onChange={(e) => setSearch(e.target.value)} placeholder="username" />
      </CfInputGroup>

      <CfInputGroup>
        <CfSelect
          value={protocol}
          onChange={setProtocol}
          options={[
            { label: 'https://', value: 'https' },
            { label: 'http://', value: 'http' },
          ]}
        />
        <CfInput value={host} onChange={(e) => setHost(e.target.value)} placeholder="example.com" />
        <CfButton>访问</CfButton>
      </CfInputGroup>

      <CfInputGroup stretch>
        <CfInput placeholder="搜索…" />
        <CfButton variant="primary">搜索</CfButton>
      </CfInputGroup>
    </>
  );
}`}
>
  <BasicVue client:load />
</DemoFrame>

## API · Props

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | 排列方向 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 静态标签的尺寸（控件本身用各自的 size 即可） |
| `stretch` | `boolean` | `false` | 子项等宽撑满父容器 |
