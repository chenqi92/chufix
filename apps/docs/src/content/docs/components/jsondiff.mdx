## 基础用法

`CfJsonDiff` 把 `left` / `right` 两个值各自 `JSON.stringify` 成多行字符串，再做最长公共子序列 diff。增加行绿底 `+`，删除行红底 `-`。

<DemoFrame
  vueCode={`<CfJsonDiff :left="left" :right="right" />`}
  reactCode={`<CfJsonDiff left={left} right={right} />`}
>
  <BasicVue client:load />
</DemoFrame>

## API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `left` / `right` | `unknown` | `—` | 要对比的两个值 |
| `lineNumbers` | `boolean` | `true` | 显示行号 |
| `bordered` | `boolean` | `true` | 边框 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 字号 |
