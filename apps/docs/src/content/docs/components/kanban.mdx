## 基础用法

`CfKanban` 接受 `KanbanColumn[]`：每列含 `cards`、可选 `limit`、`accent`。卡片支持 `title` / `description` / `tag` / `meta`。拖拽卡片到任意列任意位置。

<DemoFrame
  vueCode={`<CfKanban v-model="board" />`}
  reactCode={`<CfKanban value={board} onChange={setBoard} />`}
>
  <BasicVue client:load />
</DemoFrame>

## API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `modelValue` (Vue) / `value` (React) | `KanbanColumn[]` | `[]` | 全板状态 |
| `draggable` | `boolean` | `true` | 是否启用拖拽 |
| `bordered` | `boolean` | `true` | 边框 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 字号 |

事件：`cardMove({ cardId, from, to, toIndex })` 在卡片移动后触发。
