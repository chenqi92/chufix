## 基础用法

`keys` 数组表示组合键，自动用 `separator`（默认 `+`）拼接；省略时把 default slot 包在单个 `<kbd>` 里。

<DemoFrame
  vueCode={`<CfKbd :keys="['Ctrl', 'K']" />
<CfKbd :keys="['⌘', 'N']" />
<CfKbd>Caps Lock</CfKbd>
<CfKbd :keys="['Shift', 'Alt', 'F']" size="sm" />`}
  reactCode={`<CfKbd keys={['Ctrl', 'K']} />
<CfKbd keys={['⌘', 'N']} />
<CfKbd>Caps Lock</CfKbd>
<CfKbd keys={['Shift', 'Alt', 'F']} size="sm" />`}
>
  <BasicVue client:load />
</DemoFrame>

## API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `keys` | `string[]` | `[]` | 组合键数组，每个元素渲染成单独的 `<kbd>` |
| `separator` | `string` | `'+'` | 多键之间的分隔符 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 尺寸 |
