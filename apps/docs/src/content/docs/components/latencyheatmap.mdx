## API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `data` | `number[][]` | `—` | rows × cols 数值矩阵 |
| `rowLabels / colLabels` | `string[]` | `—` |  |
| `min / max` | `number` | `自动` | 颜色映射区间 |
