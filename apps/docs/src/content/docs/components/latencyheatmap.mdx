## 一周 × 24 小时

行 = 周一到周日，列 = 小时。颜色映射到 `oklch(70% 0.16 H)` 中 H 从 152（绿）→ 78（黄）→ 22（红）。

import WeekVue from '~/components/demos/latencyheatmap/WeekVue.vue';
import WeekVueSource from '~/components/demos/latencyheatmap/WeekVue.vue?raw';

<DemoFrame
  vueCode={`<CfLatencyHeatmap :data="data" :row-labels="days" :col-labels="hours" />`}
  reactCode={`<CfLatencyHeatmap data={data} rowLabels={days} colLabels={hours} />`}

  vueSource={WeekVueSource}>
  <WeekVue client:load />
</DemoFrame>

## API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `data` | `number[][]` | `—` | rows × cols 数值矩阵 |
| `rowLabels / colLabels` | `string[]` | `—` |  |
| `min / max` | `number` | 自动 | 颜色映射区间 |
| `width` | `number` | `480` | SVG 宽度 |
| `height` | `number` | `240` | SVG 高度 |
| `ariaLabel` | `string` | `—` | 透传给根 `<svg>` 的 `aria-label` |

### Events

| Vue 事件 | React 回调 | 载荷类型 | 说明 |
|---|---|---|---|
| `item-enter` | `onItemEnter` | `LatencyHeatmapInteractionPayload` | 鼠标进入某格时触发 |
| `item-leave` | `onItemLeave` | `LatencyHeatmapInteractionPayload` | 鼠标离开某格时触发 |

### 类型

```ts
interface LatencyHeatmapInteractionPayload {
  row: number;
  col: number;
  value: number;
  rowLabel?: string;
  colLabel?: string;
  nativeEvent?: PointerEvent;
}
```
