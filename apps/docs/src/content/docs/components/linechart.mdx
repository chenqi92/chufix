import DemoFrame from '~/components/DemoFrame.astro';

## 基础用法

数据通过 props 传入，纯 SVG 渲染，无第三方图表库依赖。
配色取自 `--viz-1..8` token，色盲友好。

<DemoFrame
  vueCode={`<CfLineChart ... />`}
  reactCode={`<CfLineChart ... />`}
>
  <BasicVue client:load />
</DemoFrame>


## 平滑曲线

`smooth = true` 走 Catmull-Rom 风格的 cubic Bezier，控制点取相邻两点的差值乘以 0.2 张力，
不会过冲（不会出现拐点处的"半圆"鼓包）。

import SmoothVue from '~/components/demos/linechart/SmoothVue.vue';

<DemoFrame
  vueCode={`<CfLineChart :series="series" smooth />`}
  reactCode={`<CfLineChart series={series} smooth />`}
>
  <SmoothVue client:load />
</DemoFrame>

## 多 series

最多支持 8 条同时显示，配色按 `--viz-1..8` 依次循环。

import MultiSeriesVue from '~/components/demos/linechart/MultiSeriesVue.vue';

<DemoFrame
  vueCode={`<CfLineChart :series="series" smooth />`}
  reactCode={`<CfLineChart series={series} smooth />`}
>
  <MultiSeriesVue client:load />
</DemoFrame>

## API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `series` | `LineSeries[]` | `—` | &#123; name?, data: number[] &#125;[] |
| `labels` | `string[]` | `自动 0..n-1` | x 轴标签 |
| `width / height` | `number` | `480 / 240` |  |
| `smooth` | `boolean` | `false` | 平滑曲线 |
| `showGrid / showLabels` | `boolean` | `true` |  |
| `yLabelFn` | `(v) => string` | `v.toFixed(0)` | y 轴标签格式化 |
