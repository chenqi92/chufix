## 基础用法

打开 Modal 后试试：**Tab / Shift+Tab 焦点环绕在弹窗内**，**ESC 关闭并把焦点送回触发按钮**，**body 滚动被锁住**。

<DemoFrame
  vueCode={`<script setup lang="ts">
import { ref } from 'vue';
import { Button, Modal, Input } from '@chukit/vue';

const open = ref(false);
const name = ref('');
</script>

<template>
  <Button @click="open = true">打开 Modal</Button>

  <Modal v-model:open="open" title="新建项目">
    <Input v-model="name" placeholder="项目名" autofocus />
    <template #footer>
      <Button variant="ghost" @click="open = false">取消</Button>
      <Button @click="open = false">创建</Button>
    </template>
  </Modal>
</template>`}
  reactCode={`import { useState } from 'react';
import { Button, Modal, Input } from '@chukit/react';

export default function Demo() {
  const [open, setOpen] = useState(false);
  const [name, setName] = useState('');

  return (
    <>
      <Button onClick={() => setOpen(true)}>打开 Modal</Button>

      <Modal
        open={open}
        onOpenChange={setOpen}
        title="新建项目"
        footer={
          <>
            <Button variant="ghost" onClick={() => setOpen(false)}>取消</Button>
            <Button onClick={() => setOpen(false)}>创建</Button>
          </>
        }
      >
        <Input value={name} autoFocus
               placeholder="项目名"
               onChange={(e) => setName(e.target.value)} />
      </Modal>
    </>
  );
}`}
>
  <BasicVue slot="vue" client:load />
  <BasicReact slot="react" client:load />
</DemoFrame>

## Props

| 名称              | Vue                       | React                                  | 默认值   | 说明                              |
| ----------------- | ------------------------- | -------------------------------------- | -------- | --------------------------------- |
| open              | `v-model:open`            | `open` + `onOpenChange`                | `false`  | 控制显隐                          |
| `title`           | `string`                  | `ReactNode`                            | —        | 头部标题（也可用 header 插槽/prop） |
| `size`            | `'sm' \| 'md' \| 'lg' \| 'xl' \| 'full'` | 同左                  | `'md'`   | 最大宽度                          |
| `closeOnOverlay`  | `boolean`                 | 同左                                   | `true`   | 点击遮罩关闭                      |
| `closeOnEsc`      | `boolean`                 | 同左                                   | `true`   | ESC 关闭                          |
| `showClose`       | `boolean`                 | 同左                                   | `true`   | 右上角关闭按钮                    |
| 容器              | `to` *(Teleport target)*  | `container` *(HTMLElement)*            | `body`   | Portal 目标                       |

## 内置行为

- **Portal**：Vue `<Teleport>` / React `createPortal`，挂到 `document.body` 避免被父级 `overflow: hidden` 截断；
- **Focus trap**：打开时焦点进入弹窗第一个可聚焦元素，Tab/Shift+Tab 在弹窗内循环，关闭后焦点回到触发器；
- **Body 滚动锁**：打开时锁定 body 滚动并补偿滚动条宽度，避免页面跳动；多个 Modal 嵌套时引用计数；
- **进出动画**：Vue 走 `<Transition name="ck-modal">`，React 走 `data-state="open|closed"` + 180ms 延迟卸载，CSS 完全一致。

## 槽位与插槽

| 位置   | Vue                          | React                |
| ------ | ---------------------------- | -------------------- |
| 头部   | `<template #header>` 或 `title` prop | `header` 或 `title` prop |
| 主体   | 默认插槽                     | `children`           |
| 底部   | `<template #footer>`         | `footer` prop        |
