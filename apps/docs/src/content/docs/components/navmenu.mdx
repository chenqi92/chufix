## 基础用法

`items` 是一个数组，每项要么是简单链接（`href`），要么有 `links[]` 列表。后者会在 hover / click 时打开富面板，每条 link 可带 `description` 与 `icon`。

`columns` 控制面板每行多少链接（1 / 2 / 3）。

<DemoFrame
  vueCode={`<script setup lang="ts">
import { ref } from 'vue';

const items: NavMenuItem[] = [
  {
    key: 'products',

## API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `items` | `NavMenuItem[]` | `[]` | 顶级菜单条目 |
| `active` | `string` | `—` | 当前活动项的 `key`，影响下划线 / 高亮 |
| `variant` | `'underline' \| 'pill' \| 'minimal'` | `'underline'` | 视觉模式 |
| `trigger` | `'hover' \| 'click'` | `'hover'` | 富面板的触发方式 |

`NavMenuItem`：`{ key, label, href?, links?, columns?, disabled? }`。
`NavMenuLink`：`{ label, description?, href, icon? }`。

事件：`navigate(item)`（React 端：`onNavigate`），仅在简单链接被点击（无 links 子项）时触发。
