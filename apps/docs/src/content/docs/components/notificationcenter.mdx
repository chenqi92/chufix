## 基础用法

每条通知是结构化数据 `{ id, title, description?, tone?, timestamp?, read?, actionLabel? }`。
未读项左侧显示彩色圆点。

<DemoFrame
  vueCode={`<CfNotificationCenter
  :items="items"
  @item-action="onAction"
  @mark-all-read="markAllRead"
  @clear-all="clearAll"
/>`}
  reactCode={`<CfNotificationCenter
  items={items}
  onItemAction={onAction}
  onMarkAllRead={markAllRead}
  onClearAll={clearAll}
/>`}

  vueSource={BasicVueSource}>
  <BasicVue client:load />
</DemoFrame>


## 空状态

`items: []` 时显示 `emptyText`；可按需替换为自定义文案。

import EmptyVue from '~/components/demos/notificationcenter/EmptyVue.vue';
import EmptyVueSource from '~/components/demos/notificationcenter/EmptyVue.vue?raw';

<DemoFrame
  vueCode={`<CfNotificationCenter :items="[]" empty-text="目前没有通知" />`}
  reactCode={`<CfNotificationCenter items={[]} emptyText="目前没有通知" />`}

  vueSource={EmptyVueSource}>
  <EmptyVue client:load />
</DemoFrame>

## API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `items` | `NotificationItem[]` | — | |
| `open` | `boolean` | `true` | 显示控制 |
| `showMarkAllRead` / `showClearAll` | `boolean` | `true` | |
| `emptyText` | `string` | `'没有通知'` | |
| `maxHeight` | `number \| string` | `480` | 滚动区高度 |

事件：`item-click` / `item-action` / `mark-all-read` / `clear-all` / `close`。
