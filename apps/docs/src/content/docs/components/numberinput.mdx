## 基础用法

`step` 设小数会自动推断 `precision`（`step=0.05` → 显示 2 位小数）。可通过键盘 ↑/↓ 步进，离焦自动 clamp 到 [min, max]。

<DemoFrame
  vueCode={`<CfNumberInput v-model="a" :min="0" :max="100" />
<CfNumberInput v-model="b" :step="0.05" :min="0" :max="1" />
<CfNumberInput v-model="c" placeholder="可空" />

<CfNumberInput v-model="d" size="sm" />
<CfNumberInput v-model="d" size="lg" />

<CfNumberInput v-model="d" hide-steppers />`}
  reactCode={`<CfNumberInput value={a} onChange={setA} min={0} max={100} />
<CfNumberInput value={b} onChange={setB} step={0.05} min={0} max={1} />
<CfNumberInput value={c} onChange={setC} placeholder="可空" />

<CfNumberInput value={d} onChange={setD} size="sm" />
<CfNumberInput value={d} onChange={setD} size="lg" />

<CfNumberInput value={d} onChange={setD} hideSteppers />`}
>
  <BasicVue client:load />
</DemoFrame>

## API

| Prop                                  | 类型               | 默认值  | 说明                        |
| ------------------------------------- | ------------------ | ------- | --------------------------- |
| `modelValue` (Vue) / `value` (React)  | `number \| null`   | `null`  | 当前值；`null` 表示空        |
| `min`                                 | `number`           | —       | 最小值                      |
| `max`                                 | `number`           | —       | 最大值                      |
| `step`                                | `number`           | `1`     | 步进                        |
| `precision`                           | `number`           | 推断    | 小数位数；不传从 step 推断   |
| `size`                                | `'sm' \| 'md' \| 'lg'` | `'md'` | 高度                        |
| `hideSteppers`                        | `boolean`          | `false` | 隐藏 +/− 按钮（仍可键盘步进）|
| `disabled`                            | `boolean`          | `false` | 禁用                        |

### 键盘

- `↑` / `↓`：按 step 步进
- 输入完按 `Enter` 或离焦：commit + clamp
