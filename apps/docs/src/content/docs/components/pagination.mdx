## 基础用法

传 `total`（总条数）和 `pageSize`（每页条数），组件自动算页数。`v-model` (Vue) / `value` + `onChange` (React) 绑定当前页（1-based）。

<DemoFrame
  vueCode={`<CfPagination v-model="page" :total="80" :page-size="10" />`}
  reactCode={`<CfPagination value={page} onChange={setPage} total={80} pageSize={10} />`}

  vueSource={BasicVueSource}>
  <BasicVue client:load />
</DemoFrame>

## 显示总数 / 跳转输入

`showTotal` 在左侧加「共 N 条」文案；`showJumper` 在右侧加「跳至 N 页」输入框（按 Enter 或离焦提交）。两个开关相互独立。

<DemoFrame
  vueCode={`<CfPagination

## 邻接页码数量

`siblingCount` 控制当前页两侧显示几个相邻页码 — 默认 `1`。结合首尾页一起最多渲染 `siblingCount * 2 + 5` 个按钮，超出会插入省略号 `…`。

## 与外部 pageSize 选择器配合

Pagination 自身不内置 "每页条数" 选择器，但与一个外部 Select 组合就能得到完整的列表分页栏。
切换 pageSize 时通常需要重置到第 1 页，避免 page 越界。

import WithPageSizeVue from '~/components/demos/pagination/WithPageSizeVue.vue';
import WithPageSizeVueSource from '~/components/demos/pagination/WithPageSizeVue.vue?raw';

<DemoFrame
  vueCode={`<script setup lang="ts">
import { watch, ref } from 'vue';
import { CfPagination, CfSelect } from '@chufix-design/vue';

const page = ref(1);
const pageSize = ref(10);
const total = 243;

watch(pageSize, () => { page.value = 1; });
</script>

<template>
  <CfSelect v-model="pageSize" :options="pageOptions" size="sm" />
  <CfPagination v-model="page" :total="total" :page-size="pageSize" size="sm" />
</template>`}
  reactCode={`import { useEffect, useState } from 'react';
import { CfPagination, CfSelect } from '@chufix-design/react';

export default function Demo() {
  const [page, setPage] = useState(1);
  const [pageSize, setPageSize] = useState(10);
  useEffect(() => { setPage(1); }, [pageSize]);

  return (
    <>
      <CfSelect value={pageSize} onChange={setPageSize} options={pageOptions} size="sm" />
      <CfPagination value={page} onChange={setPage} total={243} pageSize={pageSize} size="sm" />
    </>
  );
}`}

  vueSource={WithPageSizeVueSource}>
  <WithPageSizeVue client:load />
</DemoFrame>

## API

### Props

| Prop | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `modelValue` (Vue) / `value` (React) | `number` | `1` | 当前页（1-based） |
| `total` | `number` | `0` | 总条数 |
| `pageSize` | `number` | `10` | 每页条数 |
| `siblingCount` | `number` | `1` | 当前页两侧显示几个相邻页码 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 按钮高度 |
| `showNav` | `boolean` | `true` | 显示上一页 / 下一页箭头 |
| `showJumper` | `boolean` | `false` | 显示跳转输入 |
| `showTotal` | `boolean` | `false` | 显示「共 N 条」文案 |

### Events

| Vue 事件            | React 回调  | 载荷类型 | 说明                  |
| ------------------- | ----------- | -------- | --------------------- |
| `update:modelValue` | `onChange`  | `number` | 切换页码时触发，1-based |
