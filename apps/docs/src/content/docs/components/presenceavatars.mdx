## 基础用法

`users` 数组每项 `{ id, name, avatar?, color?, self?, away? }`。超过 `max` 的合并成 +N。

<DemoFrame
  vueCode={`<script setup>
import { CfPresenceAvatars } from '@chufix-design/vue';

const users = [
  { id: 'me', name: '我', self: true },
  { id: 'u1', name: 'Alice' },
  { id: 'u2', name: 'Bo' },
];
</script>

<template>
  <CfPresenceAvatars :users="users" :max="5" />
</template>`}
  reactCode={`const users: PresenceUser[] = [
  { id: 'me', name: '我', self: true },
  { id: 'u1', name: 'Alice' },
];

<CfPresenceAvatars users={users} max={5} />`}
  vueSource={BasicVueSource}>
  <BasicVue client:load />
</DemoFrame>

## API

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `users` | `PresenceUser[]` | — | |
| `max` | `number` | `5` | 超出折叠为 +N |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | |
| `showSelfFirst` | `boolean` | `true` | 把 self 排在前 |
