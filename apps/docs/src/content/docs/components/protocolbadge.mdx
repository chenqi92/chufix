## 基础用法

支持 GET / POST / PUT / PATCH / DELETE / HEAD / OPTIONS（HTTP）+ WS / MQTT / gRPC / SSE / GraphQL（传输 / 协议）。
颜色由 `--proto-*` token 决定，色盲友好（额外用首字母编码）。

## CfMethodBadge 别名

`CfMethodBadge` 是 `CfProtocolBadge` 的别名导出，语义上专用于 HTTP method 列表。

## API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `kind` | `ProtocolKind \| string` | — | 大小写不敏感；未识别值显示原文 + 默认灰背景 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 32×16 / 38×18 / 46×22 |

`ProtocolKind = 'get' | 'post' | 'put' | 'patch' | 'del' | 'delete' | 'head' | 'options' | 'opt' | 'ws' | 'mqtt' | 'grpc' | 'sse' | 'gql' | 'graphql'`
