## API

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `tone` | `'success' \| 'warning' \| 'error' \| 'info' \| 'accent' \| 'default'` | `'success'` | |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | |
| `pulse` | `boolean` | `true` | 关闭后只显示静态点 |
| `label` | `string` | — | 文字标签 |
