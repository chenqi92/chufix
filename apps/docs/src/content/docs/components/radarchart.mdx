## 基础用法

数据通过 props 传入，纯 SVG 渲染，无第三方图表库依赖。
配色取自 `--viz-1..8` token，色盲友好。

  vueCode={`<CfRadarChart ... />`}
  reactCode={`<CfRadarChart ... />`}
>

</DemoFrame>

## API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `axes` | `string[]` | `—` | 维度名 |
| `series` | `RadarSeries[]` | `—` | &#123; name, values: number[], colorIndex? &#125;[] |
| `size` | `number` | `240` |  |
| `max` | `number` | `数据最大值` | 标准化基准 |
