## 基础用法

`RadioGroup` 通过 `provide` / `Context` 把 `value`、`name`、`size`、`disabled` 注入到子项。任一子项被选中时回调 `update:modelValue` / `onChange`。

<DemoFrame
  vueCode={`<script setup lang="ts">
import { ref } from 'vue';
import { CfRadio, CfRadioGroup } from '@chufix-design/vue';

const plan = ref<'free' | 'pro' | 'team'>('pro');
</script>

<template>
  <CfRadioGroup v-model="plan" name="plan">
    <CfRadio value="free">Free</CfRadio>
    <CfRadio value="pro">Pro</CfRadio>
    <CfRadio value="team">Team</CfRadio>
  </CfRadioGroup>
</template>`}
  reactCode={`import { useState } from 'react';
import { CfRadio, CfRadioGroup } from '@chufix-design/react';

export default function Demo() {
  const [plan, setPlan] = useState<'free' | 'pro' | 'team'>('pro');
  return (
    <CfRadioGroup value={plan} name="plan" onChange={(v) => setPlan(v as any)}>
      <CfRadio value="free">Free</CfRadio>
      <CfRadio value="pro">Pro</CfRadio>
      <CfRadio value="team">Team</CfRadio>
    </CfRadioGroup>
  );
}`}

  vueSource={BasicVueSource}>
  <BasicVue client:load />
</DemoFrame>

## 排列方向

`direction="column"` 把选项垂直排开。在选项较多或文案较长时使用。

## 事件与表单

`change` 会返回选中的值，同时透出 `name`、`checked` 与原生事件，适合表单联动、埋点、权限策略切换等场景。事件从 `RadioGroup` 发出时，meta 来自实际触发的子项。

<DemoFrame
  vueCode={`<script setup lang="ts">
import { ref } from 'vue';
import { CfRadio, CfRadioGroup } from '@chufix-design/vue';

const region = ref('cn');
</script>

<template>
  <CfRadioGroup v-model="region" name="deploy-region" @change="(value, meta) => console.log(value, meta.name)">
    <CfRadio value="cn">华东节点</CfRadio>
    <CfRadio value="eu">欧洲节点</CfRadio>
    <CfRadio value="us">美西节点</CfRadio>
  </CfRadioGroup>
</template>`}
  reactCode={`<CfRadioGroup
  value={region}
  name="deploy-region"
  onChange={(value, meta) => {
    setRegion(value as string);
    console.log(meta.name, meta.checked);
  }}
>
  <CfRadio value="cn">华东节点</CfRadio>
  <CfRadio value="eu">欧洲节点</CfRadio>
  <CfRadio value="us">美西节点</CfRadio>
</CfRadioGroup>`}

  vueSource={EventsVueSource}>
  <EventsVue client:load />
</DemoFrame>

## API

### Props · RadioGroup

| Prop         | 类型                                  | 默认值  | 说明                                       |
| ------------ | ------------------------------------- | ------- | ------------------------------------------ |
| `modelValue` | `string \| number \| boolean \| null` | `null`  | 当前选中值（v-model；React 端用 `value`）  |
| `name`       | `string`                              | —       | 透传给底层 input 用于表单提交              |
| `size`       | `'sm' \| 'md' \| 'lg'`                | `'md'`  | 整组尺寸                                   |
| `disabled`   | `boolean`                             | `false` | 整组禁用                                   |
| `direction`  | `'row' \| 'column'`                   | `'row'` | 排列方向                                   |

### Props · Radio

| Prop         | 类型                                  | 默认值  | 说明                                                  |
| ------------ | ------------------------------------- | ------- | ----------------------------------------------------- |
| `value`      | `string \| number \| boolean \| null` | —       | 单项的值，必填                                        |
| `modelValue` | `string \| number \| boolean \| null` | `null`  | 独立使用时的受控值（脱离 RadioGroup）                 |
| `size`       | `'sm' \| 'md' \| 'lg'`                | `'md'`  | 独立使用时的尺寸（在 RadioGroup 内会被组级 size 覆盖）|
| `disabled`   | `boolean`                             | `false` | 单独禁用此项（叠加 RadioGroup.disabled）              |
| `name`       | `string`                              | —       | 独立使用时的原生 input name                           |
| `id`         | `string`                              | —       | 原生 input id，便于外部 label 关联                    |

### Events

| 事件 | 载荷 | 说明 |
|---|---|---|
| `update:modelValue` / — | `RadioValue` | v-model 隐式监听（RadioGroup 与独立 Radio 均支持） |
| `change` / `onChange` | `(value, meta)` | 选中值变化；`meta` 包含 `event`、`value`、`name`、`checked` |
| `focus` / `onFocus` | `FocusEvent` | 单个 Radio 获得焦点（仅 Radio 触发） |
| `blur` / `onBlur` | `FocusEvent` | 单个 Radio 失去焦点（仅 Radio 触发） |

### Slots / Children

| Slot      | 组件          | Props | 说明                                                     |
| --------- | ------------- | ----- | -------------------------------------------------------- |
| `default` | `Radio`       | —     | 单项 label 文案；React 端等价为 `children`               |
| `default` | `RadioGroup`  | —     | 放置一组 `<CfRadio>`；React 端等价为 `children`          |

> Radio 也可以脱离 RadioGroup 独立使用，自行管理 `v-model` / `checked + onChange`。
