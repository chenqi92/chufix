## 基础用法

`RadioGroup` 通过 `provide` / `Context` 把 `value`、`name`、`size`、`disabled` 注入到子项；任一子项被选中时回调 `update:modelValue` / `onChange`。

<DemoFrame
  vueCode={`<script setup lang="ts">
import { ref } from 'vue';
import { Radio, RadioGroup } from '@chukit/vue';

const plan = ref<'free' | 'pro' | 'team'>('pro');
</script>

<template>
  <RadioGroup v-model="plan" name="plan">
    <Radio value="free">Free</Radio>
    <Radio value="pro">Pro</Radio>
    <Radio value="team">Team</Radio>
  </RadioGroup>

  <RadioGroup v-model="plan" direction="column">
    <Radio value="free">竖直方向</Radio>
    <Radio value="pro" disabled>禁用项</Radio>
  </RadioGroup>
</template>`}
  reactCode={`import { useState } from 'react';
import { Radio, RadioGroup } from '@chukit/react';

export default function Demo() {
  const [plan, setPlan] = useState<'free' | 'pro' | 'team'>('pro');

  return (
    <>
      <RadioGroup value={plan} name="plan" onChange={(v) => setPlan(v as any)}>
        <Radio value="free">Free</Radio>
        <Radio value="pro">Pro</Radio>
        <Radio value="team">Team</Radio>
      </RadioGroup>

      <RadioGroup value={plan} direction="column" onChange={(v) => setPlan(v as any)}>
        <Radio value="free">竖直方向</Radio>
        <Radio value="pro" disabled>禁用项</Radio>
      </RadioGroup>
    </>
  );
}`}
>
  <BasicVue slot="vue" client:load />
  <BasicReact slot="react" client:load />
</DemoFrame>

## RadioGroup Props

| 名称        | 类型                                   | 默认值  | 说明                          |
| ----------- | -------------------------------------- | ------- | ----------------------------- |
| `value`     | `string \| number \| boolean \| null`  | `null`  | 当前选中值                    |
| `name`      | `string`                               | —       | 透传给底层 input 用于表单提交 |
| `size`      | `'sm' \| 'md' \| 'lg'`                 | `'md'`  | 整组尺寸                      |
| `disabled`  | `boolean`                              | `false` | 整组禁用                      |
| `direction` | `'row' \| 'column'`                    | `'row'` | 排列方向                      |

## Radio Props

| 名称       | 类型                                  | 默认值  | 说明                                    |
| ---------- | ------------------------------------- | ------- | --------------------------------------- |
| `value`    | `string \| number \| boolean \| null` | —       | 单项的值                                |
| `disabled` | `boolean`                             | `false` | 单独禁用此项（叠加 RadioGroup.disabled）|

## 独立使用

`Radio` 也可以脱离 `RadioGroup` 独立使用，此时通过 `v-model` / `checked + onChange` 自行管理状态。
