## 基础用法

`v-model` / `value` 接收 `[number, number]`。键盘 ↑↓←→ / PageUp / PageDown / Home / End 全支持。

<DemoFrame
  vueCode={`<CfRangeSlider v-model="range" :min="0" :max="100" />`}
  reactCode={`<CfRangeSlider value={range} onChange={setRange} min={0} max={100} />`}
>
  <BasicVue client:load />
</DemoFrame>


## 色调

`tone` 控制填充色（success / warning / error）；与 `Slider` 共享 `--cf-rs-*` token。

import TonesVue from '~/components/demos/rangeslider/TonesVue.vue';

<DemoFrame
  vueCode={`<CfRangeSlider v-model="v" tone="success" />`}
  reactCode={`<CfRangeSlider value={v} onChange={setV} tone="success" />`}
>
  <TonesVue client:load />
</DemoFrame>

## API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `modelValue` / `value` | `[number, number]` | `[0, 100]` | |
| `min` / `max` | `number` | `0` / `100` | |
| `step` | `number` | `1` | 步长 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | |
| `tone` | `'default' \| 'success' \| 'warning' \| 'error'` | `'default'` | |
| `disabled` / `showTooltip` | `boolean` | `false` / `true` | |
