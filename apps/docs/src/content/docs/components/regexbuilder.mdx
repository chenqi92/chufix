## 基础用法

输入 pattern + 选 flags，实时编译并在 test text 上高亮匹配。
若 pattern 编译失败，显示原生 `SyntaxError.message`。

<DemoFrame
  vueCode={`<CfRegexBuilder
  :pattern="pattern"
  :flags="flags"
  :test-text="text"
  @update:pattern="setPattern"
  @update:flags="setFlags"
  @update:test-text="setText"
/>`}
  reactCode={`<CfRegexBuilder
  pattern={pattern}
  onPatternChange={setPattern}
  flags={flags}
  onFlagsChange={setFlags}
  testText={text}
  onTestTextChange={setText}
/>`}
>
  <BasicVue client:load />
</DemoFrame>

## API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `pattern` | `string` | `''` | |
| `flags` | `string` | `'g'` | 任意子集：`g i m s u y` |
| `testText` | `string` | `''` | |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | |
| `patternPlaceholder` / `testPlaceholder` | | | |

> 安全：组件内部用 `new RegExp()`。请勿把不可信用户字符串当 pattern 直接执行 ReDoS 攻击 —— 内部循环上限 5000 命中。
