## 基础用法

`status` 控制内置状态插图与默认标题；`#extra`（Vue）/ `extra` prop（React）放置后续操作按钮。

<DemoFrame
  vueCode={`<CfResult status="success" title="提交成功" description="申请已发送给管理员，预计 1 个工作日内处理。">
  <template #extra>
    <CfButton variant="primary">返回首页</CfButton>
    <CfButton variant="tertiary">再交一份</CfButton>
  </template>
</CfResult>`}
  reactCode={`<CfResult
  status="success"
  title="提交成功"
  description="申请已发送给管理员，预计 1 个工作日内处理。"
  extra={<>
    <CfButton variant="primary">返回首页</CfButton>
    <CfButton variant="tertiary">再交一份</CfButton>
  </>}
/>`}

  vueSource={BasicVueSource}>
  <BasicVue client:load />
</DemoFrame>

## 异常状态

`404` / `403` / `500` 默认使用内置 SVG 状态插图，颜色跟随语义 token。也可以用 `image` 换成业务内置图片，或用 `#icon`（Vue）/ `icon` prop（React）完全自定义图标。

<DemoFrame
  vueCode={`<CfResult status="404" size="sm" description="页面可能已移动或被删除。" />
<CfResult status="403" size="sm" description="当前账号没有访问权限。" />
<CfResult status="500" size="sm" description="服务暂时不可用，请稍后重试。" />`}
  reactCode={`<CfResult status="404" size="sm" description="页面可能已移动或被删除。" />
<CfResult status="403" size="sm" description="当前账号没有访问权限。" />
<CfResult status="500" size="sm" description="服务暂时不可用，请稍后重试。" />`}

  vueSource={StatusesVueSource}>
  <StatusesVue client:load />
</DemoFrame>

## API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `status` | `'success' \| 'info' \| 'warning' \| 'error' \| '404' \| '403' \| '500'` | `'info'` | 状态语义；映射到默认状态插图和默认标题 |
| `title` | `string` | 与 `status` 对应的默认文案 | 主标题 |
| `description` | `string` | `—` | 副标题 |
| `image` | `string` | `—` | 自定义插图图片地址；不传时使用内置 SVG 状态插图 |
| `imageAlt` | `string` | `''` | 自定义图片的替代文本；装饰图保持空字符串 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 整体尺寸 |

Slot（Vue）/ prop（React）：`icon` 自定义图标或任意视觉节点，`extra` 操作区。
