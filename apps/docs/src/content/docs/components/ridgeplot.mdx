## 基础用法

数据通过 props 传入，纯 SVG 渲染，无第三方图表库依赖。
配色取自 `--viz-1..8` token，色盲友好。

<DemoFrame
  vueCode={`<CfRidgePlot ... />`}
  reactCode={`<CfRidgePlot ... />`}

  vueSource={BasicVueSource}>
  <BasicVue client:load />
</DemoFrame>


## 多峰分布

把多个 bell 叠加可得到双峰分布，常见于跨季节、跨用户群的二次集中点。

import SeasonsVue from '~/components/demos/ridgeplot/SeasonsVue.vue';
import SeasonsVueSource from '~/components/demos/ridgeplot/SeasonsVue.vue?raw';

<DemoFrame
  vueCode={`<CfRidgePlot :rows="rows" :overlap="0.5" />`}
  reactCode={`<CfRidgePlot rows={rows} overlap={0.5} />`}

  vueSource={SeasonsVueSource}>
  <SeasonsVue client:load />
</DemoFrame>

## API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `rows` | `RidgeRow[]` | `—` | &#123; label, density: number[], colorIndex? &#125;[] |
| `overlap` | `0..1` | `0.6` | 行间重叠比例 |
