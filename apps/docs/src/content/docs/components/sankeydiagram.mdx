配色取自 `--viz-1..8` token，色盲友好。

## API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `nodes` | `SankeyNode[]` | `—` | &#123; id, name, layer?, colorIndex? &#125;[] |
| `links` | `SankeyLink[]` | `—` | &#123; source, target, value &#125;[] |
| `nodeWidth` | `number` | `12` | 节点条宽 |
