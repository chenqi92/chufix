## 基础用法

左侧固定 search 图标；非空时右侧出现 × 清空按钮，点击清空并触发 `clear`。回车触发 `search(value)`。

<DemoFrame
  vueCode={`<CfSearchInput
  v-model="q"
  placeholder="搜索文档…"
  @search="(v) => console.log(v)"
/>`}
  reactCode={`<CfSearchInput
  value={q}
  onChange={setQ}
  placeholder="搜索文档…"
  onSearch={(v) => console.log(v)}
/>`}

  vueSource={BasicVueSource}>
  <BasicVue client:load />
</DemoFrame>

## 快捷键提示

`shortcut` 在最右挂一个 `kbd` 提示文本。常配合页面级监听 `Ctrl K` / `⌘K` 跳到搜索框。

<DemoFrame
  vueCode={`<CfSearchInput v-model="q" placeholder="按 Ctrl K 聚焦" shortcut="Ctrl K" />`}
  reactCode={`<CfSearchInput value={q} onChange={setQ} placeholder="按 Ctrl K 聚焦" shortcut="Ctrl K" />`}

  vueSource={ShortcutVueSource}>
  <ShortcutVue client:load />
</DemoFrame>

## API

| Prop | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `modelValue` (Vue) / `value` (React) | `string` | `''` | 当前值 |
| `placeholder` | `string` | `'搜索…'` | 占位提示 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 高度 |
| `disabled` | `boolean` | `false` | 禁用 |
| `clearable` | `boolean` | `true` | 显示清空按钮（值非空时） |
| `shortcut` | `string` | — | 右侧 kbd 提示文本 |

事件：

- Vue：`@update:modelValue`、`@search`、`@clear`
- React：`onChange`、`onSearch`、`onClear`
