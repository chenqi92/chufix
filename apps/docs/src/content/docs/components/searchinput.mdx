## 基础用法

非空时右侧自动出 × 清空按钮，回车触发 `search` 事件。`shortcut` 在最右显示一个 `kbd` 提示（`Ctrl K` / `⌘K` 等）。

<DemoFrame
  vueCode={`<script setup lang="ts">
import { ref } from 'vue';
import { CfSearchInput } from '@chufix/vue';

const q = ref('');
</script>

<template>
  <CfSearchInput v-model="q" placeholder="搜索文档…" @search="(v) => console.log(v)" />
  <CfSearchInput v-model="q" placeholder="带快捷键提示" shortcut="Ctrl K" />
  <CfSearchInput v-model="q" size="sm" placeholder="小" />
  <CfSearchInput v-model="q" size="lg" placeholder="大" />
</template>`}
  reactCode={`import { useState } from 'react';
import { CfSearchInput } from '@chufix/react';

const [q, setQ] = useState('');

<CfSearchInput value={q} onChange={setQ} onSearch={(v) => console.log(v)} />
<CfSearchInput value={q} onChange={setQ} shortcut="Ctrl K" />
<CfSearchInput value={q} onChange={setQ} size="sm" />
<CfSearchInput value={q} onChange={setQ} size="lg" />`}
>
  <BasicVue client:load />
</DemoFrame>

## API

| Prop                                  | 类型                  | 默认值    | 说明                       |
| ------------------------------------- | --------------------- | --------- | -------------------------- |
| `modelValue` (Vue) / `value` (React)  | `string`              | `''`      | 当前值                     |
| `placeholder`                         | `string`              | `'搜索…'` | 占位提示                   |
| `size`                                | `'sm' \| 'md' \| 'lg'` | `'md'`   | 高度                       |
| `disabled`                            | `boolean`             | `false`   | 禁用                       |
| `clearable`                           | `boolean`             | `true`    | 显示清空按钮               |
| `shortcut`                            | `string`              | —         | 右侧 kbd 提示文本          |

### 事件

- Vue：`@update:modelValue`、`@search`、`@clear`
- React：`onChange`、`onSearch`、`onClear`
