## 基础用法

`CfSegmentedControl` 等价于 `<CfTabs variant="segmented" />`，只是导出名更直观。API 与 Tabs 的 `value` / `items` / `size` / `align` 一致。

<DemoFrame
  vueCode={`<CfSegmentedControl
  v-model="view"
  :items="[
    { value: 'list', label: '列表' },
    { value: 'card', label: '卡片' },
    { value: 'kanban', label: '看板' },
  ]"
/>
<CfSegmentedControl
  v-model="period"
  size="sm"
  :items="[
    { value: 'day', label: '日' },
    { value: 'week', label: '周' },
    { value: 'month', label: '月' },
    { value: 'year', label: '年' },
  ]"
/>`}
  reactCode={`<CfSegmentedControl
  value={view}
  items={[
    { value: 'list', label: '列表' },
    { value: 'card', label: '卡片' },
    { value: 'kanban', label: '看板' },
  ]}
  onChange={setView}
/>
<CfSegmentedControl
  value={period}
  size="sm"
  items={[
    { value: 'day', label: '日' },
    { value: 'week', label: '周' },
    { value: 'month', label: '月' },
    { value: 'year', label: '年' },
  ]}
  onChange={setPeriod}
/>`}
>
  <BasicVue client:load />
</DemoFrame>

## API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `modelValue` (Vue) / `value` (React) | `string` | `—` | 当前选中 value |
| `items` | `SegmentedItem[]` | `[]` | `{ value, label, disabled? }` |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 尺寸 |
| `align` | `'start' \| 'center' \| 'end' \| 'stretch'` | `'start'` | 对齐方式 |

如果你需要 line / pill 样式或多视图切换，请直接使用 [Tabs](/components/tabs/)。
