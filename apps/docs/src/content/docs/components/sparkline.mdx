## 8 色调色板

通过 `colorIndex`（0..7）选 `--viz-1..8` 任一色号，色盲友好且与图表系列色统一。

import ColorsVue from '~/components/demos/sparkline/ColorsVue.vue';
import ColorsVueSource from '~/components/demos/sparkline/ColorsVue.vue?raw';

<DemoFrame
  vueCode={`<CfSparkline :data="data" :color-index="0" filled smooth />
<CfSparkline :data="data" :color-index="3" filled smooth />`}
  reactCode={`<CfSparkline data={data} colorIndex={0} filled smooth />
<CfSparkline data={data} colorIndex={3} filled smooth />`}

  vueSource={ColorsVueSource}>
  <ColorsVue client:load />
</DemoFrame>

## API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `data` | `number[]` | `—` | 数据点数组 |
| `width / height` | `number` | `80 / 24` |  |
| `filled` | `boolean` | `false` | 显示填充面积 |
| `smooth` | `boolean` | `false` | 平滑曲线 |
| `colorIndex` | `0..7` | `0` | 颜色索引（--viz-&#123;n+1&#125;） |
| `showDot` | `boolean` | `true` | 高亮最后一个点 |
