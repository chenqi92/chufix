## 基础用法

`size` 控制大小，`tone` 控制颜色，`label` 在右侧加可读文案（也作为 aria-label）。

<DemoFrame
  vueCode={`<CfSpinner size="sm" />
<CfSpinner size="md" />
<CfSpinner size="lg" />

<CfSpinner tone="success" />
<CfSpinner tone="danger" />
<CfSpinner tone="neutral" />

<CfSpinner label="正在加载…" />`}
  reactCode={`<CfSpinner size="sm" />
<CfSpinner size="md" />
<CfSpinner size="lg" />

<CfSpinner tone="success" />
<CfSpinner tone="danger" />
<CfSpinner tone="neutral" />

<CfSpinner label="正在加载…" />`}
>
  <BasicVue client:load />
</DemoFrame>

## API

| Prop    | 类型                                                              | 默认值      | 说明              |
| ------- | ----------------------------------------------------------------- | ----------- | ----------------- |
| `size`  | `'sm' \| 'md' \| 'lg'`                                            | `'md'`      | 尺寸              |
| `tone`  | `'primary' \| 'success' \| 'warning' \| 'danger' \| 'info' \| 'neutral'` | `'primary'` | 颜色              |
| `label` | `string`                                                          | —           | 文字标签 + aria-label |
