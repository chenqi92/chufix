## 基础用法

数据通过 props 传入，纯 SVG 渲染，无第三方图表库依赖。
配色取自 `--viz-1..8` token，色盲友好。

<DemoFrame
  vueCode={`<CfStackedBar100 ... />`}
  reactCode={`<CfStackedBar100 ... />`}
>
  <BasicVue client:load />
</DemoFrame>


## 趋势对比

把多年份的占比柱叠在一起，能直观看出份额迁移。

import CompareVue from '~/components/demos/stackedbar100/CompareVue.vue';

<DemoFrame
  vueCode={`<CfStackedBar100 :segments="seg2024" />
<CfStackedBar100 :segments="seg2025" />`}
  reactCode={`<CfStackedBar100 segments={seg2024} />
<CfStackedBar100 segments={seg2025} />`}
>
  <CompareVue client:load />
</DemoFrame>
