## 基础用法

底层是 `<CfInput type="checkbox" role="switch">`，键盘 / 表单 / 屏幕阅读器全部直接可用。

<DemoFrame
  vueCode={`<script setup lang="ts">
import { ref } from 'vue';
import { CfSwitch } from '@chufix-design/vue';

const wifi = ref(true);
</script>

<template>
  <CfSwitch v-model="wifi">Wi-Fi {{ wifi ? '已开启' : '已关闭' }}</CfSwitch>
</template>`}
  reactCode={`import { useState } from 'react';
import { CfSwitch } from '@chufix-design/react';

export default function Demo() {
  const [wifi, setWifi] = useState(true);
  return (
    <CfSwitch checked={wifi} onChange={(e) => setWifi(e.target.checked)}>
      Wi-Fi {wifi ? '已开启' : '已关闭'}
    </CfSwitch>
  );
}`}

  vueSource={BasicVueSource}>
  <BasicVue client:load />
</DemoFrame>

## 状态

`loading` 在 thumb 内显示 spinner 并暂时阻止切换；`disabled` 禁用整个开关。

<DemoFrame
  vueCode={`<script setup lang="ts">
import { ref } from 'vue';
import { CfSwitch } from '@chufix-design/vue';

const sync = ref(false);
const loading = ref(false);

async function toggle(v: boolean) {
  loading.value = true;
  await new Promise((r) => setTimeout(r, 1000));
  sync.value = v;
  loading.value = false;
}
</script>

<template>
  <CfSwitch :model-value="sync" :loading="loading" @change="toggle">
    自动同步（点击触发 1s 异步）
  </CfSwitch>
  <CfSwitch :model-value="true" disabled>禁用 · 已开</CfSwitch>
</template>`}
  reactCode={`import { useState } from 'react';
import { CfSwitch } from '@chufix-design/react';

export default function Demo() {
  const [sync, setSync] = useState(false);
  const [loading, setLoading] = useState(false);

  async function toggle(e) {
    setLoading(true);
    await new Promise((r) => setTimeout(r, 1000));
    setSync(e.target.checked);
    setLoading(false);
  }

  return (
    <>
      <CfSwitch checked={sync} loading={loading} onChange={toggle}>
        自动同步（点击触发 1s 异步）
      </CfSwitch>
      <CfSwitch checked disabled>禁用 · 已开</CfSwitch>
    </>
  );
}`}

  vueSource={StatesVueSource}>
  <StatesVue client:load />
</DemoFrame>

## 事件与异步

`loading` 会暂时阻止再次切换，适合保存设置、权限开关、远程同步等异步场景。`change` 会携带 checked 与 name，React 额外提供 `onCheckedChange` 便于直接拿布尔值。

<DemoFrame
  vueCode={`<CfSwitch
  :model-value="enabled"
  :loading="loading"
  name="auto-sync"
  @change="async (checked, meta) => {
    loading = true;
    await save(checked, meta.name);
    enabled = checked;
    loading = false;
  }"
>
  自动同步
</CfSwitch>`}
  reactCode={`<CfSwitch
  checked={enabled}
  loading={loading}
  name="auto-sync"
  onCheckedChange={async (checked, meta) => {
    setLoading(true);
    await save(checked, meta.name);
    setEnabled(checked);
    setLoading(false);
  }}
>
  自动同步
</CfSwitch>`}

  vueSource={EventsVueSource}>
  <EventsVue client:load />
</DemoFrame>

## API

### Props

| Prop         | 类型                   | 默认值  | 说明                                                        |
| ------------ | ---------------------- | ------- | ----------------------------------------------------------- |
| `modelValue` | `boolean`              | `false` | 受控值；React 端用 `checked` + `onChange` 或 `onCheckedChange` |
| `size`       | `'sm' \| 'md' \| 'lg'` | `'md'`  | 整体尺寸                                                    |
| `disabled`   | `boolean`              | `false` | 禁用                                                        |
| `loading`    | `boolean`              | `false` | 显示 spinner，并暂时阻止切换                                |
| `name`       | `string`               | —       | 原生 input name                                             |
| `id`         | `string`               | —       | 原生 input id                                               |

### Events

| Vue 事件 | React 回调 | payload | 说明 |
|---|---|---|---|
| `update:modelValue` | — | `boolean` | v-model 隐式监听 |
| `change` | `onCheckedChange` | `(checked, { event, checked, name })` | 切换状态变化 |
| `focus` / `blur` | `onFocus` / `onBlur` | `FocusEvent` | 原生焦点事件 |

### Slots / Children

| Slot      | Props | 说明                                                  |
| --------- | ----- | ----------------------------------------------------- |
| `default` | —     | label 文案；React 端等价为 `children`，与开关右侧对齐 |

### 双向绑定

- **Vue**：`v-model` 绑定到 `boolean`；`@change` 拿到 `boolean` 值。
- **React**：受控传 `checked` + `onChange`；非受控传 `defaultChecked`。`onChange` 是原生 ChangeEvent，`onCheckedChange` 直接返回布尔值。
