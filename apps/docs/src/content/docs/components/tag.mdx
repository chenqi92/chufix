## 基础用法

`variant`（视觉强度）与 `tone`（语义色）正交组合。`closable` 渲染一个 × 按钮，点击触发 `close` / `onClose`。

<DemoFrame
  vueCode={`<script setup lang="ts">
import { ref } from 'vue';
import { Tag } from '@chukit/vue';

const tags = ref(['Vue', 'Astro', 'Tailwind']);
</script>

<template>
  <Tag tone="primary">Primary</Tag>
  <Tag tone="success">Success</Tag>
  <Tag tone="danger">Danger</Tag>

  <Tag variant="solid" tone="primary">Solid</Tag>
  <Tag variant="outline" tone="primary">Outline</Tag>
  <Tag tone="success" rounded>圆角</Tag>

  <Tag
    v-for="t in tags"
    :key="t"
    closable
    @close="tags = tags.filter(x => x !== t)"
  >{{ t }}</Tag>
</template>`}
  reactCode={`import { useState } from 'react';
import { Tag } from '@chukit/react';

export default function Demo() {
  const [tags, setTags] = useState(['Vue', 'Astro', 'Tailwind']);

  return (
    <>
      <Tag tone="primary">Primary</Tag>
      <Tag tone="success">Success</Tag>
      <Tag tone="danger">Danger</Tag>

      <Tag variant="solid" tone="primary">Solid</Tag>
      <Tag variant="outline" tone="primary">Outline</Tag>
      <Tag tone="success" rounded>圆角</Tag>

      {tags.map((t) => (
        <Tag
          key={t}
          closable
          onClose={() => setTags((xs) => xs.filter((x) => x !== t))}
        >{t}</Tag>
      ))}
    </>
  );
}`}
>
  <BasicVue slot="vue" client:load />
  <BasicReact slot="react" client:load />
</DemoFrame>

## Props

| 名称       | 类型                                                          | 默认值      | 说明                          |
| ---------- | ------------------------------------------------------------- | ----------- | ----------------------------- |
| `variant`  | `'solid' \| 'soft' \| 'outline'`                              | `'soft'`    | 视觉变体                      |
| `tone`     | `'neutral' \| 'primary' \| 'success' \| 'warning' \| 'danger' \| 'info'` | `'neutral'` | 语义色                        |
| `size`     | `'sm' \| 'md' \| 'lg'`                                        | `'md'`      | 高度与字号                    |
| `rounded`  | `boolean`                                                     | `false`     | 圆角到 pill                   |
| `closable` | `boolean`                                                     | `false`     | 显示 × 关闭按钮               |

## 插槽 / Children

- **Vue**：默认插槽是文本；`leading` 具名插槽放图标。
- **React**：`children` 是文本；`leading` prop 放图标节点。
