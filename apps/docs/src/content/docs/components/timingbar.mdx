## API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `phases` | `TimingPhase[]` | `—` | &#123; label, start, end, colorIndex? &#125;[]（ms） |
| `showAxis` | `boolean` | `true` | 底部段标签 |
