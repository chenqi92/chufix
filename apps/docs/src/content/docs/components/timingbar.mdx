## 基础用法

配色取自 `--viz-1..8` token，色盲友好。

  reactCode={`<CfTimingBar ... />`}

## 真实瀑布场景

3 个并发 HTTP 请求的 timing 拼接：DNS / Connect / TLS / Wait / Receive 各色。

import RealVue from '~/components/demos/timingbar/RealVue.vue';

<DemoFrame
  vueCode={`<CfTimingBar :phases="phases" />`}
  reactCode={`<CfTimingBar phases={phases} />`}
>
  <RealVue client:load />
</DemoFrame>

## API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `phases` | `TimingPhase[]` | `—` | &#123; label, start, end, colorIndex? &#125;[]（ms） |
| `showAxis` | `boolean` | `true` | 底部段标签 |
| `labelMode` | `'auto' \| 'all' \| 'none'` | `'auto'` | 段标签显示策略，默认自动避让重叠 |
