## 基础用法

在应用根布局挂一次 `<Toaster />`，然后在任何地方调用 `toast()` / `toast.success()` 即可。底层是一个框架无关的 pub-sub store，组件订阅后渲染队列。

<DemoFrame
  vueCode={`<script setup lang="ts">
import { Button, Toaster, toast } from '@chukit/vue';
</script>

<template>
  <Button @click="toast({ title: '通用通知', description: '默认样式' })">默认</Button>
  <Button @click="toast.success('保存成功')">success</Button>
  <Button @click="toast.error('保存失败')">error</Button>
  <Button @click="toast.warning('磁盘空间不足')">warning</Button>
  <Button @click="toast.info('已复制到剪贴板')">info</Button>

  <Toaster position="top-right" />
</template>`}
  reactCode={`import { Button, Toaster, toast } from '@chukit/react';

export default function Demo() {
  return (
    <>
      <Button onClick={() => toast({ title: '通用通知', description: '默认样式' })}>默认</Button>
      <Button onClick={() => toast.success('保存成功')}>success</Button>
      <Button onClick={() => toast.error('保存失败')}>error</Button>
      <Button onClick={() => toast.warning('磁盘空间不足')}>warning</Button>
      <Button onClick={() => toast.info('已复制到剪贴板')}>info</Button>

      <Toaster position="top-right" />
    </>
  );
}`}
>
  <BasicVue slot="vue" client:load />
  <BasicReact slot="react" client:load />
</DemoFrame>

## API

### `toast(input)` 与衍生方法

`input` 既可以是字符串（直接当作 `title`），也可以是对象：

```ts
interface ToastInput {
  type?: 'default' | 'success' | 'error' | 'warning' | 'info';
  title?: string;
  description?: string;
  duration?: number;     // 毫秒，默认 4000；<= 0 表示不自动关闭
  dismissible?: boolean; // 是否显示关闭按钮，默认 true
}
```

| 方法                | 等价于                                  |
| ------------------- | --------------------------------------- |
| `toast(x)`          | 默认类型                                |
| `toast.success(x)`  | `toast({ ...x, type: 'success' })`      |
| `toast.error(x)`    | `toast({ ...x, type: 'error' })`        |
| `toast.warning(x)`  | `toast({ ...x, type: 'warning' })`      |
| `toast.info(x)`     | `toast({ ...x, type: 'info' })`         |
| `toast.dismiss(id)` | 关闭单个 Toast（返回值为 `id`）         |
| `toast.clear()`     | 清空所有 Toast                          |

### `<Toaster />` Props

| 名称       | 类型                                                                                                  | 默认值        | 说明     |
| ---------- | ----------------------------------------------------------------------------------------------------- | ------------- | -------- |
| `position` | `'top-right' \| 'top-left' \| 'top-center' \| 'bottom-right' \| 'bottom-left' \| 'bottom-center'`     | `'top-right'` | 渲染位置 |

## 注意事项

- **Toaster 只挂一次**：放在应用根布局即可，多挂会出现重复显示。
- **duration ≤ 0**：禁用自动关闭，需要用户手动点 × 或调用 `toast.dismiss(id)`。
- **store 跨包不共享**：Vue 与 React 各自维护一个 store；如果你在同一个页面同时用两种框架（像本站这样的 Astro 多 island），它们的 toast 是彼此独立的。
