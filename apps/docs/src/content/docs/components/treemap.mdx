## 基础用法

配色取自 `--viz-1..8` token，色盲友好。

## label 显隐

`showLabels=false` 时只展示色块，适合微缩组合。仅当矩形足够大（w>50, h>20）时才显示文字。

import LabeledVue from '~/components/demos/treemap/LabeledVue.vue';
import LabeledVueSource from '~/components/demos/treemap/LabeledVue.vue?raw';

<DemoFrame
  vueCode={`<CfTreemap :nodes="nodes" />
<CfTreemap :nodes="nodes" :show-labels="false" />`}
  reactCode={`<CfTreemap nodes={nodes} />
<CfTreemap nodes={nodes} showLabels={false} />`}

  vueSource={LabeledVueSource}>
  <LabeledVue client:load />
</DemoFrame>
