## Basic usage

Data is passed in via props and rendered as plain SVG — no third-party charting library.
Colors come from the `--viz-1..8` tokens and are color-blind friendly.

<DemoFrame
  vueCode={`<CfBarChart ... />`}
  reactCode={`<CfBarChart ... />`}
>
  <BasicVue client:load />
</DemoFrame>


## Color

`colorIndex` 0..7 selects `--viz-1..8` directly.

import SeriesColorVue from '~/components/demos/barchart/SeriesColorVue.vue';

<DemoFrame
  vueCode={`<CfBarChart :data="data" :color-index="0" />
<CfBarChart :data="data" :color-index="3" />`}
  reactCode={`<CfBarChart data={data} colorIndex={0} />
<CfBarChart data={data} colorIndex={3} />`}
>
  <SeriesColorVue client:load />
</DemoFrame>

## API

| Prop | Type | Default | Description |
|---|---|---|---|
| `data` | `number[]` | `—` | Bar heights |
| `labels` | `string[]` | `—` | x-axis labels |
| `colorIndex` | `0..7` | `0` |  |
| `width / height / showGrid / showLabels` | `` | `` |  |
