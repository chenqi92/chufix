title: BulletChart
description: Single-value progress bar with a target marker and qualitative bands — better suited than Gauge for "compare against target" semantics.
---

import DemoFrame from '~/components/DemoFrame.astro';
import BasicVue from '~/components/demos/bulletchart/BasicVue.vue';

## Basic usage

Data is passed in via props and rendered as plain SVG — no third-party charting library.
Colors come from the `--viz-1..8` tokens and are color-blind friendly.

<DemoFrame
  vueCode={`<CfBulletChart ... />`}
  reactCode={`<CfBulletChart ... />`}
>
  <BasicVue client:load />
</DemoFrame>


## Bands + exceeding target

`bands` provides three colored segments and `target` draws a vertical line; when the value exceeds the target the bar extends past it.

import BandsVue from '~/components/demos/bulletchart/BandsVue.vue';

<DemoFrame
  vueCode={`<CfBulletChart :value="92" :target="80" :max="100" :bands="bands" />`}
  reactCode={`<CfBulletChart value={92} target={80} max={100} bands={bands} />`}
>
  <BandsVue client:load />
</DemoFrame>

## API

| Prop | Type | Default | Description |
|---|---|---|---|
| `value` | `number` | `—` | Current value |
| `target` | `number` | `—` | Target value (vertical line) |
| `max` | `number` | `—` | Maximum value |
| `bands` | `{ upTo: number; tone? }[]` | `[]` | Qualitative bands (poor/ok/good) |
| `label` | `string` | `—` |  |
