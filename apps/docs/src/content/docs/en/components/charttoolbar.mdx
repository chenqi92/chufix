## Basic usage

Data is passed in via props and rendered as plain SVG — no third-party charting library.
Colors come from the `--viz-1..8` tokens and are color-blind friendly.

  vueCode={`<CfChartToolbar ... />`}
  reactCode={`<CfChartToolbar ... />`}

</DemoFrame>


## Live interaction

Click a legend chip to toggle a series; the LineChart below redraws in real time.

import InteractiveVue from '~/components/demos/charttoolbar/InteractiveVue.vue';
import InteractiveVueSource from '~/components/demos/charttoolbar/InteractiveVue.vue?raw';

<DemoFrame
  vueCode={`<CfChartToolbar :series="series" @series-toggle="toggle" />
<CfLineChart :series="visibleSeries" />`}
  reactCode={`<CfChartToolbar series={series} onSeriesToggle={toggle} />
<CfLineChart series={visibleSeries} />`}

  vueSource={InteractiveVueSource}>
  <InteractiveVue client:load />
</DemoFrame>

## API

| Prop | Type | Default | Description |
|---|---|---|---|
| `title / subtitle` | `string` | `—` | Title and description |
| `series` | `LegendSeries[]` | `—` | &#123; name, colorIndex, hidden? &#125;[]; clicking a legend item triggers toggle |
| `showZoom / showExport / showRefresh` | `boolean` | `false` | Show button slots |
