## Basic usage

Without props, renders a single horizontal solid line that separates surrounding content.

## Three line styles

`variant` — `solid` (default), `dashed`, or `dotted`. The default slot becomes the inline label.

<DemoFrame
  vueCode={`<CfDivider variant="solid">solid</CfDivider>

<CfDivider variant="dotted">dotted</CfDivider>`}

## Label alignment

`align` — `start`, `center` (default), or `end`. Controls the horizontal position of the label.

## Vertical divider

`orientation="vertical"` switches to a vertical line, useful for separating inline segments. Vertical also supports `variant`.

<DemoFrame
  vueCode={`<span>Left</span>
<CfDivider orientation="vertical" />
<span>Middle</span>
<CfDivider orientation="vertical" variant="dashed" />
<span>Right</span>`}
  reactCode={`<span>Left</span>
<CfDivider orientation="vertical" />
<span>Middle</span>
<CfDivider orientation="vertical" variant="dashed" />
<span>Right</span>`}

  vueSource={VerticalVueSource}>
  <VerticalVue client:load />
</DemoFrame>

## API

| Prop | Type | Default | Description |
|---|---|---|---|
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | Direction |
| `variant` | `'solid' \| 'dashed' \| 'dotted'` | `'solid'` | Line style |
| `align` | `'start' \| 'center' \| 'end'` | `'center'` | Label position (horizontal only) |
