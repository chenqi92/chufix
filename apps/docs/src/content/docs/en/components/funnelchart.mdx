## Basic usage

Data is passed in via props. Pure SVG rendering, no third-party chart library dependency.
Colors come from the `--viz-1..8` tokens and are colorblind-friendly.

<DemoFrame
  vueCode={`<CfFunnelChart ... />`}
  reactCode={`<CfFunnelChart ... />`}
>

</DemoFrame>


## Healthy vs leaky funnel

A healthy funnel (30–50% drop per step) versus a leaky funnel (92% drop right after the first step).

import CompareVue from '~/components/demos/funnelchart/CompareVue.vue';

<DemoFrame
  vueCode={`<CfFunnelChart :steps="good" />
<CfFunnelChart :steps="bad" />`}
  reactCode={`<CfFunnelChart steps={good} />
<CfFunnelChart steps={bad} />`}
>
  <CompareVue client:load />
</DemoFrame>
