## Basic usage

Differences from [CommandPalette](/components/commandpalette/): this component is a full-screen overlay (`paddingTop 8vh`) with built-in category filter chips and a three-column title/path/badge layout.
Use it for "application spotlight" use cases; the command palette is for "Cmd+K command search".

<DemoFrame
  vueCode={`<CfGlobalSearch
  :open="open"
  :results="results"
  @update:open="setOpen"
  @select="onSelect"
/>`}
  reactCode={`<CfGlobalSearch
  open={open}
  onOpenChange={setOpen}
  results={results}
  onSelect={onSelect}
/>`}

  vueSource={BasicVueSource}>
  <BasicVue client:only="vue" />
</DemoFrame>


## Category filter

18 results across 5 categories. Click a top chip to filter; the chip row is hidden automatically when there is at most one category.

import CategoriesVue from '~/components/demos/globalsearch/CategoriesVue.vue';
import CategoriesVueSource from '~/components/demos/globalsearch/CategoriesVue.vue?raw';

<DemoFrame
  vueCode={`<CfGlobalSearch ... :show-categories="true" />`}
  reactCode={`<CfGlobalSearch ... showCategories />`}

  vueSource={CategoriesVueSource}>
  <CategoriesVue client:load />
</DemoFrame>

## API

| Prop | Type | Default | Description |
|---|---|---|---|
| `open` / `v-model:open` | `boolean` | — | |
| `results` | `GlobalSearchResult[]` | — | `{ id, title, description?, category, badge?, path?, shortcut?, keywords?, disabled? }` |
| `placeholder` / `emptyText` | | | |
| `showCategories` | `boolean` | `true` | Top category chips |
| `closeOnSelect` | `boolean` | `true` | |
| `to` | `string \| HTMLElement` | `'body'` | Teleport target; local containers keep the overlay inside the container |

Keyboard: `up/down` navigate, `enter` select, `Esc` close.
