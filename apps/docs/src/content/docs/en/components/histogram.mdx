## Basic usage

Data is passed in via props. Pure SVG rendering, no third-party chart library dependency.
Colors come from the `--viz-1..8` tokens and are colorblind-friendly.

<DemoFrame
  vueCode={`<CfHistogram ... />`}
  reactCode={`<CfHistogram ... />`}
>
  <BasicVue client:load />
</DemoFrame>


## Two typical distributions

Normal vs. long-tail distribution — for long-tailed data, consider log-scale bin labels.

import DistributionsVue from '~/components/demos/histogram/DistributionsVue.vue';

<DemoFrame
  vueCode={`<CfHistogram :bins="bins" />`}

## API

| Prop | Type | Default | Description |
|---|---|---|---|
| `bins` | `HistogramBin[]` | `—` | &#123; label, count &#125;[] |
| `colorIndex` | `0..7` | `0` |  |
| `showLabels` | `boolean` | `true` | Show/hide bin labels |
