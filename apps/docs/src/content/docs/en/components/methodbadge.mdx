`CfMethodBadge` is an alias export for [`CfProtocolBadge`](/components/protocolbadge/). When the context is unambiguously about HTTP methods, importing `CfMethodBadge` expresses intent more precisely; at runtime it is the same component.

## Basic Usage

Use it when the value is specifically an HTTP method. Colors and sizing follow `ProtocolBadge`.

<DemoFrame
  vueCode={`<CfMethodBadge kind="get" />
<CfMethodBadge kind="post" />
<CfMethodBadge kind="put" />
<CfMethodBadge kind="delete" />`}
  reactCode={`<CfMethodBadge kind="get" />
<CfMethodBadge kind="post" />
<CfMethodBadge kind="put" />
<CfMethodBadge kind="delete" />`}
  vueSource={BasicVueSource}>
  <BasicVue client:load />
</DemoFrame>

## Import

```ts
// Vue
import { CfMethodBadge } from '@chufix-design/vue';

// React
import { CfMethodBadge } from '@chufix-design/react';
```

See [ProtocolBadge](/components/protocolbadge/) for the full API.
