## Basic usage

Defaults to 4 rules (8+ chars / uppercase / digit / symbol). Override via `requirements`.

<DemoFrame
  vueCode={`<CfPasswordStrength v-model="pwd" />`}
  reactCode={`<CfPasswordStrength value={pwd} onChange={setPwd} />`}
>
  <BasicVue client:load />
</DemoFrame>


## Custom rules

Pass `requirements` to replace the 4 default rules. Each entry is `{ label, test }`.

import CustomRulesVue from '~/components/demos/passwordstrength/CustomRulesVue.vue';

<DemoFrame
  vueCode={`<CfPasswordStrength v-model="pwd" :requirements="rules" />`}
  reactCode={`<CfPasswordStrength value={pwd} onChange={setPwd} requirements={rules} />`}
>
  <CustomRulesVue client:load />
</DemoFrame>

## API

| Prop | Type | Default | Description |
|---|---|---|---|
| `modelValue` / `v-model` (Vue), `value/onChange` (React) | `string` | `''` | Password value |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | |
| `placeholder` | `string` | `'Enter password'` | |
| `disabled` | `boolean` | `false` | |
| `showToggle` | `boolean` | `true` | Show eye toggle for visibility |
| `requirements` | `PasswordRequirement[]` | `defaultPasswordRequirements` | `{ label, test }[]` |
