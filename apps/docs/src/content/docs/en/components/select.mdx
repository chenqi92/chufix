## Basic usage

Pass options via the `options` array; each item must have at least `value` and `label`.

<DemoFrame
  vueCode={`<script setup lang="ts">
import { ref } from 'vue';
import { CfSelect, type SelectOption } from '@chufix-design/vue';

const options: SelectOption[] = [
  { value: 'beijing', label: 'Beijing' },
  { value: 'shanghai', label: 'Shanghai' },
  { value: 'guangzhou', label: 'Guangzhou' },
];

const city = ref<string | null>('shanghai');
</script>

<template>
  <CfSelect v-model="city" :options="options" placeholder="Pick a city" />
</template>`}
  reactCode={`import { useState } from 'react';
import { CfSelect, type SelectOption } from '@chufix-design/react';

const options: SelectOption[] = [
  { value: 'beijing', label: 'Beijing' },
  { value: 'shanghai', label: 'Shanghai' },
  { value: 'guangzhou', label: 'Guangzhou' },
];

export default function Demo() {
  const [city, setCity] = useState<string | null>('shanghai');
  return (
    <CfSelect
      value={city}
      options={options}
      placeholder="Pick a city"
      onChange={(v) => setCity(v as string | null)}
    />
  );
}`}
>
  <BasicVue client:load />
</DemoFrame>

## States and clearable

`clearable` shows × once a value is selected; `disabled` disables the whole control; `error` switches to the error border color. An individual option can set `disabled: true` to be skipped.

## Keyboard interaction

| Key               | Behavior                                |
| ----------------- | --------------------------------------- |
| `↓` / `↑`         | Open menu / move active item            |
| `Enter` / `Space` | Open menu / select active item          |
| `Esc`             | Close menu                              |
| `Tab`             | Close menu and return focus to browser  |

## API

| Prop          | Type                               | Default      | Description                             |
| ------------- | ---------------------------------- | ------------ | --------------------------------------- |
| `options`     | `SelectOption[]`                   | `[]`         | Options array, `{ value, label, disabled? }` |
| `placeholder` | `string`                           | `'Select'`   | Shown when nothing is selected          |
| `variant`     | `'outline' \| 'filled' \| 'ghost'` | `'outline'`  | Visual variant                          |
| `size`        | `'sm' \| 'md' \| 'lg'`             | `'md'`       | Overall size                            |
| `clearable`   | `boolean`                          | `false`      | Show clear button when something is selected |
| `disabled`    | `boolean`                          | `false`      | Disable the whole control               |
| `error`       | `boolean`                          | `false`      | Error state                             |

> The current implementation uses `position: absolute` for the popup. If a parent's `overflow: hidden` clips the menu, a Portal version will be added later.
