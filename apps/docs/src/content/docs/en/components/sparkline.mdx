## Basic usage

Data is passed via props and rendered as pure SVG, with no third-party charting dependency.
Colors are drawn from the `--viz-1..8` tokens and are colorblind-friendly.

<DemoFrame
  vueCode={`<CfSparkline ... />`}
  reactCode={`<CfSparkline ... />`}

  vueSource={BasicVueSource}>
  <BasicVue client:load />
</DemoFrame>


## 8-color palette

`colorIndex` (0..7) picks any color in `--viz-1..8` — colorblind-friendly and aligned with chart series colors.

import ColorsVue from '~/components/demos/sparkline/ColorsVue.vue';
import ColorsVueSource from '~/components/demos/sparkline/ColorsVue.vue?raw';

<DemoFrame
  vueCode={`<CfSparkline :data="data" :color-index="0" filled smooth />

  reactCode={`<CfSparkline data={data} colorIndex={0} filled smooth />
<CfSparkline data={data} colorIndex={3} filled smooth />`}

  vueSource={ColorsVueSource}>
  <ColorsVue client:load />
</DemoFrame>

## API

| Prop | Type | Default | Description |
|---|---|---|---|
| `data` | `number[]` | `—` | Array of data points |
| `width / height` | `number` | `80 / 24` |  |
| `filled` | `boolean` | `false` | Show filled area |
| `smooth` | `boolean` | `false` | Smooth curve |
| `colorIndex` | `0..7` | `0` | Color index (--viz-&#123;n+1&#125;) |
| `showDot` | `boolean` | `true` | Highlight the last point |
