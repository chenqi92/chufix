---
title: 安装
description: 在 Vue 3 或 React 项目里安装并使用 ChuFix UI。
order: 1
---

## Vue 3

```bash
npm i @chufix/vue
```

```ts
// main.ts
import { createApp } from 'vue';
import App from './App.vue';
import '@chufix/vue/style.css';

createApp(App).mount('#app');
```

```vue
<script setup lang="ts">
import { CfButton } from '@chufix/vue';
</script>

<template>
  <CfButton>Hello ChuFix</CfButton>
</template>
```

## React

```bash
npm i @chufix/react
```

```ts
// main.tsx
import '@chufix/react/style.css';
```

```tsx
import { CfButton } from '@chufix/react';

export default () => <CfButton>Hello ChuFix</CfButton>;
```

## 源码拷贝模式

如果你想完全控制组件源码：

```bash
npx chufix add button
```

执行后 ChuFix 会把 `button/Button.vue`（或 `Button.tsx`）+ 对应的 `button.css` 直接放进你项目里指定的目录，之后改成什么样都随你。

## Tailwind CSS（可选）

```ts
// tailwind.config.ts
import preset from '@chufix/tokens/tailwind';

export default {
  presets: [preset],
  content: ['./src/**/*.{vue,tsx,ts,html}'],
};
```

之后即可 `<div class="bg-chufix-primary text-chufix-primary-fg" />` 这样使用。
