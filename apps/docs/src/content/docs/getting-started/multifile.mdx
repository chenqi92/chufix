单文件 demo 用 `DemoFrame`（顶部代码区 + Vue / React × TS / JS 切换）。

多文件示例（例如未来的后台管理系统，含用户管理、角色管理等多个页面）改用 `DocCodeWorkspace`：左侧文件树，右侧编辑器，框架与语言切换在 IDE 顶部完成。

下面是一个最小验证示例：3 个文件 × Vue / React × TS / JS（JS 由 TS 自动生成）。

export const bundles = buildWorkspaceBundles({ vueFiles, reactFiles });

<DocCodeWorkspace
  bundles={bundles}
  title="admin-mini · source"
  rootLabel="admin-mini"
  height="min(620px, 70vh)"
/>

## 接入方式

```ts
import DocCodeWorkspace from '~/components/DocCodeWorkspace.astro';
import { buildWorkspaceBundles } from '~/components/docCode';

const bundles = buildWorkspaceBundles({
  vueFiles: { 'src/App.vue': '...', 'src/pages/Users.vue': '...' },
  reactFiles: { 'src/App.tsx': '...', 'src/pages/Users.tsx': '...' },
});
```

- `vueFiles` / `reactFiles` 都是 `Record<path, TypeScript source>`。
- JS 变体由 `buildWorkspaceBundles` 内部用 `toJavaScript` 同步生成（去掉 `lang="ts"` / 类型注解 / `import type` / `interface` 等）。
- 只提供 `vueFiles` 时，仅出现 Vue 一组 tab；同理 React。
- 通过 `includeJs: false` 可关闭 JS 变体自动生成。
