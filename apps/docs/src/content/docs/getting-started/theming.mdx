ChuFix UI 所有视觉表现都从 CSS 变量里读，集中定义在 `@chufix/tokens/tokens.css`。

## 切换暗色模式

```html
<html data-theme="dark">...</html>
```

或运行时切换：

```ts
document.documentElement.dataset.theme =
  document.documentElement.dataset.theme === 'dark' ? 'light' : 'dark';
```

## 自定义主色

```css
:root {
  --cf-primary: 280 78% 56%;        /* HSL 三通道，无 hsl() 包裹 */
  --cf-primary-hover: 280 78% 50%;
  --cf-primary-active: 280 78% 44%;
  --cf-primary-soft: 280 78% 96%;
}
```

token 用 HSL 通道格式而不是 `#hex` 是为了 `hsl(var(--cf-primary) / 0.5)` 能直接在样式里加透明度。

## 完整 token 清单

颜色：`--cf-bg` `--cf-fg` `--cf-muted` `--cf-muted-fg` `--cf-border` `--cf-ring` `--cf-primary*` `--cf-danger*` `--cf-success` `--cf-warning`

形状：`--cf-radius-sm` `--cf-radius` `--cf-radius-lg` `--cf-radius-pill`

字体：`--cf-font-sans`

阴影：`--cf-shadow-sm` `--cf-shadow` `--cf-shadow-lg`

动画：`--cf-duration-fast` `--cf-duration` `--cf-easing`
